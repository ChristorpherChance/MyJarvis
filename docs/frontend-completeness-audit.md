## 新代码的重点复核

1. 总览六域与矩阵切换、四环数值来自现有记录；总览/七屏1366×768及手机宽度核对，不让未知值出现 NaN 或虚构0%。
2. 提醒直达真实对象：书目/疑点、故事/补充/课程、任务、服务/部署、审批、备份/恢复；同页换记录也能刷新详情。
3. 家庭三轮练习与语音练习结束后，学习计划读取当前人 data.learning；旧记录未存答句/纠错就明确缺项；当前人的故事进度继续独立保留。
4. 公共屏不读取他人学习分钟、记忆或健康；切身份后本人课程、收藏、练习与详情均重算。
5. 十主题真实造型、对话75/25、沉浸纯对话、详情弹窗及移动布局保持既有改善。
6. 已有真实API仅用于已接能力；未接执行器、语音、OCR、外部来源、部署与记忆不伪造成功或真实数据。
