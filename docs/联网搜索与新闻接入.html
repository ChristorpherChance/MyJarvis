联网搜索与新闻接入

查询真实公开资料，回答保留来源链接与时间。临时数据库、隔离 HTTP 与公共来源已验收，未调用收费模型或改动正式数据。正式部署由统一发布流程完成。

联网搜索

Bing 公开搜索 RSS，真实标题、链接、摘要、抓取时间。

非商业 API，无 SLA；搜索 RSS 日期不等于网页发布时间。

公开网页

提取静态正文，保留原链接与截断标记。

不登录、不转发 Cookie、不执行 JavaScript。

来源新闻

中新网、联合国中文与 NASA 官方 RSS。

保留发布方日期和失败状态，不能声称覆盖所有热点。

通过对话使用

询问“今天有什么新闻”“帮我查最新资料”或“读这个网页”时，Pi 可调用 jarvis_web_search、jarvis_read_page、jarvis_news。回答附真实来源链接；网页中的提示词没有批准或执行权限。

本人“仅本地”策略禁止外部请求；“每次询问”需要用户本轮明确许可。工具参数没有自行授予许可的字段。缓存按成员隔离，设置与计数持久保存，查询正文不写入联网资料库。

接口与管理

方法地址作用
GET/api/runtime/web/state本人能力与当前资料策略
GET / PUT/api/runtime/web/settings管理员读取或按 expectedVersion 保存策略
GET/api/runtime/web/feeds已启用新闻源
POST/api/runtime/web/searchquery、count、language
POST/api/runtime/web/readurl、maxChars
POST/api/runtime/web/newsfeedIds、query、count、withinHours

POST 统一采用 {input:{…},networkConsent?}，有效身份必需。默认 12 秒、1 MiB、60 秒短缓存；每成员每分钟 12 次、每天 200 次，整体并发和总请求也有上限。新闻无日期明确标记，有日期旧条目按窗口过滤，失联不生成替代新闻。

安全与证据

每次访问与重定向都检查地址和全部 DNS 结果，阻止内网、环回、元数据与非 HTTP(S)；连接固定到已验证 IP，TLS 验证原域名。限制体积、重定向、耗时与并发，断开会取消上游，权限或设置变化会阻止旧结果交付。

专项测试：apps/api/test/web-runtime.test.ts。真实公共来源验收：scripts/verify-web-runtime.ts，报告 artifacts/web-runtime/live-source-smoke.json。2026-10-10 实际读取 Bing、TypeScript 文档及三个新闻源，零收费模型调用。
