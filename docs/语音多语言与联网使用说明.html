开始交流

从平台“语音对话 → 语音交流”进入，验证本人身份，点击“开始交流”。输入始终自动识别中文、英语、法语、德语，不需要选择说话语言。手机请使用 HTTPS，并允许麦克风与声音播放；应用内置浏览器受限时可在系统浏览器打开。

“回复语言”只控制贾维斯的输出：

回复设置 贾维斯的行为
自动跟随 跟随本轮实际识别的语言；文字提问则根据当前文字判断
中文 无论用哪种支持的语言提问，都用中文回答
English / Français / Deutsch 固定使用对应语言回答

偏好保存在当前家庭成员的中心档案，跨手机、电脑和房间终端生效。管理员也可在“家庭成员 → 专属管家”设置每个人的回复语言。交流中修改偏好，从下一轮开始生效；本轮已开始的回答和声音保持一致。旧版浏览器的语言选择不会强制新识别。

当前家庭安排：我、老婆、大儿子、小儿子固定英语；爸爸、妈妈固定中文。开场招呼、等待提示、正式答案使用同一偏好。自动模式在首次尚未听到原话时以中文开场，听到原话后跟随实际语言。

语音输入仍由多语言 Whisper 检测语言，中文检测成功后使用 SenseVoice 识别；声音输出按实际回复语言选择 Matcha/Kokoro 或对应语言的 Piper。语言练习中的目标示例与讲解分别选择声音：例如固定英语讲解、法语练习题用法语朗读。目前日语、西班牙语练习目标仅显示文字，不能冒充已接入语音。

识别、模型回答、声音合成是三步，任何一步失败都会提示。短句、混合语言、口音和噪声可能影响自动判断，请核对“你说”的转录。当前本地自动识别还需要数秒，不能承诺瞬时回应。

成员识别依据当前登录或终端绑定的家庭身份，语言不会决定身份、权限或记忆归属。新建家人档案后，管理员还需要配置各自的登录凭证；当前没有声纹识别来自动区分家人。

房间提醒也使用成员偏好的语言。私人提醒只播报通用提示，详情保留在本人通知中心；家庭公开事项在正文与回复语种一致时可朗读，旧内容语种不同则提示查看详情，不把换声线当作翻译。

更换人声

点击“人声设置”，在“我的声音”中选择、试听，再点击“设为我的声音”。试听不会改变已保存选择。快速中英交流适合响应优先；多声线合成可能慢一些。英语、法语和德语会按实际回复语言使用合适人声，不能让仅支持中英的引擎冒充法语或德语发音。

“贾维斯风格”是管家语气的人声配置，不是电影演员原声复制。个人选择只影响本人；恢复专属管家映射时选择“沿用专属管家设置”。文字页面的自动朗读与持续语音入口有不同的播放设置。

配置其他声音或自己的声音

管理员进入“系统设置 → 运行引擎 → 语音身份 → 声音合成”，可以配置兼容 HTTP 服务、模型 ID、默认声音 ID 和 clear/warm/calm 映射。外部引擎须真实提供该声音 ID；切换引擎后，个人选择先回到沿用专属管家设置，再试听验证。

当前平台没有录音上传、克隆注册或自建人声管理入口。录制一段声音不会自动得到可用的人声 ID。若声音服务已支持个人声音，可先在该服务完成注册，再通过兼容接口使用其声音 ID；原生服务若协议不同，需要专用适配器，不能仅修改地址。

后续本地定制人声可以评估 Qwen3-TTS 或 CosyVoice：需要参考音频、准确转录、声线登记、试听及删除功能，并在实际算力机器测量延迟。112 的 CPU 运行速度尚未验证，不能承诺实时克隆。

普通聊天与复杂问题

管理员在“系统设置 → 模型中心 → 智能路由”中分别选择快速模型、高级模型，并控制复杂问题等待时的简短回复。当前已启用 Kimi 高速作为快速模型、gpt-6.1-sol 作为高级模型。普通聊天使用快速模型；深度研究、复杂比较、长篇多条件问题由平台规则识别后使用高级模型。未配置高级模型时回退快速模型，界面会显示路由状态。

等待时，快速模型通过独立 Pi SDK 会话选择简短过渡回复；没有台账、工具或主会话历史，不提前声称已查到资料。正式答案开始后停止迟到的过渡，播报不会重复。过渡不会写入主对话答案，但真实模型用量单独计入治理账本。隐私设置、云端同意及打断同时约束两类模型。

实时查询先取得真实资料，再播报结果。普通、安全的闲聊支持完整句子提前合成与播放；第二句按前一句实际开始播放后预备，避免排队堆积。思考内容不进入播报。

联网搜索和新闻

可以直接说“查询今天的科技新闻，给我来源”或“搜索某个事件的最新进展，再核对原文”。贾维斯通过 Pi 只读工具联网搜索、读取公开网页和查询已配置新闻源；回答中的链接会在“相关链接”中显示。

管理员在“运行引擎 → 联网资料”启停搜索、网页读取和新闻，并维护 RSS 来源。默认查询覆盖已接入来源，不等于全网所有新闻；需要更全面的结果时可结合搜索、原文与不同来源核对。

  • 来源发布时间与本次查询时间分开展示；新闻发布时间不等于事件发生时间。
  • 搜索引擎给出的日期只是供应商日期，不能当作已核实的原文发布时间。
  • 来源失败、过旧或没有日期时明确提示，不生成替代新闻。
  • 不读取登录网页，不执行网页脚本，不访问内网设备或本机文件。
  • 本人仅本地偏好禁止外网查询；需询问偏好按当前轮的云端同意处理。

本次基准与验收

生产旧链路的三组中文合成测试：快速 Matcha 约 0.10–0.14 秒，多声线 Kokoro 约 2.8–4.4 秒。这只是合成时间，完整对话还包含收音、识别、模型和网络耗时。测试句未复现尾音“这”，不能据此宣称所有读音问题已解决。

模型连接检查：Kimi 高速约 1.02 秒，DeepSeek Flash 约 1.42 秒，当前高级模型约 2.39 秒。该测试只要求回复连接成功，不代表真实问题的首字延迟或回答质量。

生产实测已通过英语、法语、德语的模型回答与语音合成、识别回环。复杂比较问题确实进入高级模型，快速模型的等待回复先于正式回答；新闻回答引用了实际新闻查询返回的链接。

R17.1 已部署到 112 主节点与 101 冷备。四种语言的合成音频自动识别全部通过；三次真实中文、法语、德语提问在本人固定英语配置下，均收到英语回答并完成英语语音合成。法语学习请求也保持英语讲解。线上设置检查 4/4、主要接口检查 25/25 通过，六位家人的回复偏好已核对。

R16 历史报告保存在 artifacts/voice-response-r16；R17.1 的自动输入、固定输出与成员配置报告保存在 artifacts/auto-language-r17/release-verification.json。浏览器模拟测试与合成音频回环不等于实体手机麦克风、真实口音或扬声器验证。
