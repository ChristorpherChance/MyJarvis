# 中央语音与家庭身份

更新：2026-10-06。先在书房联想64GB验证，再迁移48GB正式平台，最后扩展其他房间。

## 已实现的真实闭环

房间浏览器授权麦克风后，用MediaRecorder采集实际音频，VAD在语句结束后上传二进制。后台中央ASR识别，当前已验证成员的独立Pi会话生成回答，中央TTS输出真实音频，浏览器播放并发送“开始／结束／打断／被浏览器阻止”回执。

原始录音默认不保存；仅成员主动选择`session`或`7`后保存自己的ASR输入，下载必须验证同一成员。`session`在关闭语音会话时删除，最长8小时；`7`按实际创建时间最多7天。策略改为`never`可立即清理，取消任务会撤销音频。合成音频默认仅供播放，10分钟过期，播放结束或打断后删除；明确的会话／7天策略同样适用于合成音频。后台作业有真实状态、取消、超时、并发限制、成员权限和轮次校验，重启不会自动重复请求语音引擎。

浏览器申请echoCancellation、noiseSuppression、autoGainControl；免手动播放期间，通过同一麦克风的VAD触发打断并续接。实际房间的回声、拾音距离及电视干扰仍需现场校准，不能把浏览器选项当作已验收的专业声学效果。

## 家庭身份与设备配对

管理员为实际成员档案设置密码或6至12位PIN；后台仅存scrypt盐和哈希。家庭cookie独立、HttpOnly、SameSite=strict，限时8小时。登录有持久限速。修改或停用凭据会撤销旧成员会话。

本人档案`me`在验证后共用`server-admin`数据身份，以便书房、手机和控制台共用本人记忆；权限仍是家庭成员，不发管理员cookie。其他家庭成员使用独立`member_<credential UUID>`身份，不能读取他人聊天或记忆。家庭登录会撤销当前浏览器的旧管理员登录，防止房间共享浏览器保留管理权限。管理平台需重新使用管理员密码登录。

终端配对码由管理员生成，10分钟内一次性消费。配对后终端凭据最长90天，允许成员及房间由服务端绑定；可随时撤销。设备凭据只证明已登记的房间终端，不能代替成员身份，也不会因选择档案或唤醒词而获得他人权限。

Pi对话使用现有SDK及Store会话，每次运行显式注入当前身份的只读业务查询。成员回调缺失时使用空查询，不能回落管理员资料。本人可以查询自己的管理资料；其他成员仅可查询获准家庭共享知识、待办和自己的记忆。偏好改变语气与学习安排，不改变权限。

中央语音按成员时区执行安静时间，在午夜重新计算个人每日语音预算；纽约夏令时等时区变化由`Intl`处理。分钟用实际ASR输入及TTS输出音频秒数累计，WAV校验采样参数，压缩音频由固定PyAV脚本解码计量。浏览器提供的时长不作为依据；单段输入最多65秒，无法计量的格式明确拒绝。超过预算或处于安静时间可继续文字交流。

云端偏好由后台硬性执行：`local`只允许本地模型和引擎；`ask`的外部Pi、ASR、TTS每次请求须带明确授权；`allowed`可使用已配置能力。固定本地程序和本机／私网接口按本地部署处理，未知域名按外部处理。Pi还校验SDK凭据中的真实URL覆盖，并在运行锁内重查，防止判定后切换模型绕过策略。房间的云端勾选不存库、不写浏览器存储，成员切换立即清空。

## 可执行的语音引擎

| 路线 | 行为 | 配置与依赖 |
| --- | --- | --- |
| CPU ASR | Faster-Whisper本地模型、int8、默认2线程、最多65秒单段音频 | 项目venv安装`faster-whisper>=1.2,<2`，已下载多语言tiny完整目录；运行时不自动下载模型 |
| Windows TTS | System.Speech生成WAV，不由后台扬声器播放 | 默认固定PowerShell脚本；当前联想实际有中文Huihui和英文Zira，默认按文本选语言 |
| HTTP ASR/TTS | OpenAI兼容`audio/transcriptions`与`audio/speech`，真实multipart输入和音频输出 | 配置基础地址、模型和可选密钥；可指向家中高算力接口 |
| 受控本地程序 | 固定可执行程序与参数数组，输入／输出／文本通过临时文件传递 | 绝对可执行路径、固定argv；不通过shell执行，不接受模型生成的命令 |

声音映射可把`clear`、`warm`、`calm`等档案选项映射实际引擎voiceID。没有映射时使用引擎默认声音，不把档案标签当成不存在的SAPI声音。新的语音引擎密钥以AES-GCM加密存于平台SQLite；本地解密key在`runtime/voice-master.key`，必须与数据库一同备份。配置、状态和审计不回显密钥。

成员语言传入ASR，语速传入HTTP `speed`或SAPI `Rate`。本地解码计量器复用项目venv的PyAV，不另启后台声音播放。`VoiceRuntime.options.audioProbeExecutable`应指向同一Python；PCM WAV计量不依赖外部程序。

## 浏览器与唤醒

`/?mode=room`是房间入口；平台“运行引擎”里的“语音身份”可设置凭据、配置引擎、生成配对码和打开入口。

“开始说话”支持书房初次测试。“开启免手动”在用户授权后持续检测语句；未唤醒时使用中央ASR识别当前成员唤醒词，唤醒后45秒可连续对话。房间bridge也可提交经设备凭据认证的唤醒事件；浏览器轮询后开始当前成员录音。

“我的记忆与留存”只查询当前验证成员，可主动写入候选、确认或遗忘，修改真实保存策略，选择本人会话交由Pi整理、停止整理、立即清理和导出。管理员记忆页也提供同一套本人操作。身份过期时停止麦克风、关闭免手动并清空上一位成员的界面记录；退出或离开房间页会关闭语音会话。

授权分析会话与允许云端分析是两项独立选择。记忆整理的云端勾选仅对本次执行有效，完成或切换所选会话后清空；自动整理在`ask`偏好下只走本地模型，未授权时拒绝外部分析。

这不是专业hotword或声纹模型：bridge事件不声称识别了某个人，ASR唤醒也不替代成员验证。默认不读取实际家庭声音，不自行启动麦克风。常驻终端建议HTTPS与前台全屏模式；远程房间通过普通局域网HTTP打开时，浏览器通常不会开放麦克风。应在48GB中心配置HTTPS与可信证书。

## 接口摘要

| 接口 | 权限与作用 |
| --- | --- |
| `POST /api/runtime/identity/login`、`logout`；`GET state` | 独立家庭身份；不授予管理员cookie |
| `PUT/DELETE /api/runtime/identity/profiles/:id/credential` | 管理员设置／停用实际成员凭据 |
| `POST /api/runtime/terminals/pair`、`claim` | 管理员生成一次性码；终端消费配对 |
| `GET /api/runtime/terminals/pairings`、`DELETE /:id` | 管理员查看／撤销配对，设备token不回显 |
| `/api/runtime/family/conversations`及其`messages`、`abort` | 当前成员独立Pi会话及历史 |
| `GET/PUT/DELETE /api/runtime/voice/engines`及`:kind` | 管理员查询状态与配置ASR／TTS |
| `GET /api/runtime/voice/state` | 当前身份的引擎、留存、安静时间、当日真实语音用量 |
| `POST /api/runtime/voice/sessions`、`GET /:id` | 当前身份、已配对终端、服务端房间绑定 |
| `POST /api/runtime/voice/sessions/:id/audio` | 最多25MiB实际WAV／WebM／Ogg／MP3／M4A二进制，返回异步作业 |
| `POST /api/runtime/voice/sessions/:id/speech` | 当前成员文字生成TTS作业 |
| `POST /api/runtime/voice/sessions/:id/interrupt`、`DELETE /:id` | 取消、静音、关闭及轮次失效 |
| `GET /api/runtime/voice/jobs/:id`、`audio`；`POST cancel`、`playback` | 当前成员状态、音频下载、取消与实际客户端回执 |
| `POST/GET /api/runtime/voice/wake` | 已配对bridge提交／获取终端唤醒事件 |

原V1管理员手工输入和意图确认仍保留。`VoiceRuntime.synthesize`提供原V1 TTS集成钩子，返回真实音频作业；生成成功不会被写为“已播放”。

## 验证

`apps/api/test/voice-identity-runtime.test.ts`隔离验证18项通过：凭据哈希、家庭会话隔离、限速、本人canonical身份、一次性终端配对、Pi偏好与只读回调隔离、HTTP二进制ASR／TTS、实际语言和语速、音频权限、临时播放删除、取消与超时、无shell程序适配、Windows SAPI实际WAV、ASR原音频选择保留、TTL及会话关闭清理、凭据撤销阻止晚到结果、按时区／夏令时／午夜跨日的实际采样分钟计量、每次云授权／不可覆盖local的真实门禁，以及文字不留存后安全续聊。续聊只处理Pi调用前明确的会话404；断网、503或权限失败不会自动重复Pi。

独立隐私和费用回归11项通过（`memory-governance-privacy-regression.test.ts`）：分析授权不代替本次云授权、自动分析只走获准本地模型、异步门禁后的身份锁、取消晚到结果不写记忆、自动授权撤回、生效类别限制、敏感原文证据不得自动生效、遗忘后旧提交保持脱敏，以及CLI费用去重、缺价保留未知、重启后聊天与SDK无回执费用保留未知。

语音恢复回归3项通过（`voice-key-recovery.test.ts`）：加密配置与`runtime/voice-master.key`必须来自同一完整备份。缺钥、短钥或不匹配密钥会明确停止启动，绝不生成替代密钥覆盖原文件；`createApp`释放失败时已打开的数据库与服务句柄，恢复匹配密钥后可正常启动、关闭并删除临时恢复目录。成员档案状态表达已实现的中央运行服务，同时保留引擎配置、终端配对和本人认证的独立要求。

真实本机验证已通过：System.Speech输出4.17秒WAV，PyAV编码并实际解码4.17秒WebM／Opus，Faster-Whisper tiny CPU／int8正确识别“Hello Jarvis. This is a local voice test.”，中央TTS再次输出真实WAV，收到播放结束回执后删除临时文件；真实用量累计8.34秒。适配器通过有界PyAV解码的float32 ndarray接口运行，兼容当前PyAV19。记录见`artifacts/real-local-voice-qa/report.json`。

中文链路另行真实验证4项通过（`artifacts/real-local-voice-zh-qa/report.json`）：原输入“你好，贾维斯。请告诉我今天的天气。”，5.45秒SAPI WAV编码为WebM后，经tiny实际识别的原文为“你好, 假维酥。请告诉我今天的天气。”。普通中文和天气词可识别，专名“贾维斯”未精确命中，结果原样保留；未用替换文本制造成功。中央TTS实际再次输出，播放结束回执清除临时音频，用量10.90秒。首次书房验收应先用按钮或已配好的唤醒bridge；tiny的罕见名字识别不保证能稳定触发ASR精确唤醒。

运行引擎浏览器验证7项通过：四个管理页真实加载，知识／执行／费用并发冲突保留输入，实际创建本人PIN及一次性配对码，房间成员身份不具有管理员权限；用假的MediaStream验证成员退出后迟到的麦克风授权会立即停止轨道，不启动录音。报告及6张截图在`artifacts/runtime-engines-ui-qa/`，无页面异常。模拟授权请求1次、模拟轨道停止1次，真实麦克风调用仍为0。

以上只用临时库、临时合成音频、离线Pi／本地HTTP fixture，付费模型、真实麦克风、扬声器播放、正式数据写入均为0。实际房间的拾音与回声仍需书房现场验证。
