## 启动

需要 Node.js 24。全新独立安装和构建（已迁移的联想不要用原.jarvis启动生产）：

~~~powershell
npm ci
npm run build
npm start
~~~

新独立安装默认只监听127.0.0.1:3140。联想开发使用npm run dev，前端5173、API3140、独立.jarvis-dev；生产访问112。原Windows常驻已停止，service:restart不会启动新的OS任务。两台Linux服务使用systemd，见部署文档。

程序读取系统环境变量，不自动读取.env。模型密钥通过管理页面保存，不放进项目资料、节点参数或截图。

## 本地语音与OCR

Windows书房实测使用项目隔离Python 3.12环境，按锁定文件复现依赖：

~~~powershell
py -3.12 -m venv .runtime-venv
.runtime-venv/Scripts/python.exe -m pip install -r apps/api/resources/requirements-local-runtime.lock.txt
.runtime-venv/Scripts/python.exe scripts/download-local-asr.py
~~~

RapidOCR包含轻量中英ONNX模型；下载脚本固定官方多语言tiny ASR revision，检查权重SHA256、词表及必需文件并保存hash清单。Windows TTS使用固定SAPI脚本。跨操作系统可先使用知识requirements.txt与faster-whisper>=1.2,<2选择可安装版本，另做平台测试并配置HTTP或受控程序TTS；Windows锁定文件不代表其他平台已验收。依赖安装后重启API，查看实际健康状态；配置保存不代表真实引擎验收通过。

## 局域网与48GB部署

默认不会暴露到局域网。显式配置 JARVIS_HOST、JARVIS_ALLOW_LAN=1 和精确 JARVIS_ALLOWED_HOSTS 才允许其他终端访问。JARVIS_TLS_KEY / JARVIS_TLS_CERT 指向本机PEM私钥和证书；房间麦克风使用可信HTTPS。

完整配置、现场验收与恢复步骤见[后台完整实现与验收](docs/后台完整实现与验收.md)及[HTML版](docs/后台完整实现与验收.html)。48GB的112已部署生产平台，其他实体房间仍待配置和现场验收。
