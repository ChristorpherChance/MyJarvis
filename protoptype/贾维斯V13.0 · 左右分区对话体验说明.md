# 贾维斯 V13 · 左右分区对话

打开同目录的 **贾维斯V13.0 · 十套主题与全平台交互原型.html**，即可离线体验十套主题。图片、样式、动画与模拟数据均内嵌在单个 HTML 中；V12 保留。

## 本次布局

- 桌面和横屏采用 **左侧约 75% 图像、右侧约 25% 对话与控制**。
- 左侧展示完整的主题场景与动态特效，右侧集中显示对话记录、实时字幕、聆听状态和语音控制。
- **全屏对话**隐藏平台导航、主题选择和管理入口，只保留主题画面、对话、必要控制与收拢入口。
- **收拢模式**回到平台框架中，保持相同的左右分区，可选择主题或进入其他功能。
- 手机竖屏会调整为上下布局，保证文字和语音控制易读、可操作；横屏使用左右布局。

## 如何体验

1. 默认进入全屏对话。右侧可开始说话、打断或使用文字输入。
2. 点击“收拢”即可看到主题选择和其他平台入口；切换后，对话仍在右侧。
3. 点击“展开”再次进入专注的全屏对话；设备支持时也可使用浏览器原生全屏。
4. 对话特效会随聆听、理解、回答和打断变化；右侧展示对应字幕与消息。
5. 切换主题或布局保留草稿和会话。不同家庭成员、公共身份的记录和权限继续分开。

## 原有功能

十套主题、20 个管理视图、7 类大屏，以及知识接入与校对、记忆、家庭学习、项目与开发监督、机器和服务、灵感研究、经验技能、审批继续可用。

这是用于确认产品与交互设计的模拟原型。对话特效演示默认静音；系统朗读与真实麦克风取决于设备和浏览器支持。
