# 知识资料入库闭环

本说明对应开发候选，未自动发布到正式R58平台；实际验证与限制见本轮artifacts/knowledge-ingestion。

## 从哪里开始

进入“知识接入 → 来源登记 → 资料入库”。先登记来源和有效授权。新来源默认本人私有；家庭共享须明确选择共享范围。原件、来源、知识文档的访问范围必须一致。

- **本地文档**：TXT、Markdown、CSV、JSON、DOCX使用既有原件库，保存真实字节后登记知识文档候选。通用原件上限25MiB。
- **PDF／扫描图片**：使用“PDF／图片精校入库”，保持既有32MiB原件、按页识别/人工转录、疑点裁决及逐页审核流程。不能以通用文档的一次确认代替扫描书籍精校。
- **网页资料**：仅抓取明确允许的HTTP(S)来源，保留实际原始字节；不登录网站、不执行脚本、不全站爬取。
- **NAS／指定目录**：仅读取已挂载可读且位于管理员白名单的准确目录。先预览新增/变化/未变化/移除/不支持/跳过清单，再确认同步。目录只直接解析UTF-8 TXT/MD/JSON/HTML；PDF、Office、图片需单文件解析路径。系统不自动SSH、挂载或扫描NAS全盘。

## 通用文档的人工发布

1. 保存原件并登记候选，核对当前选中的准确标题和原件SHA。
2. 若需修字，进入“原件管理与文字修订”完成修订，再对知识文档建立新修订快照；原件不变。
3. 对照原件和全部段落填写人工核对依据，再明确确认核对。
4. 单独点击发布当前版本。未审核草稿不可进入新通用文档检索集合。
5. 在联合检索中选择对应资料范围、输入原文关键字，打开命中内容核对段落、版本和SHA。

通用文档没有虚构页码。引用绑定当前来源授权、原件记录与文字版本；撤权、原件回收/删除或修订变化后，旧引用失效，需要重新核对发布。已有目录同步资料仍标注“外部来源未人工复核”，不会因本轮新增文档发布流程自动升格可信等级。

## 重试与更正

入库失败时保留本次提交编号和已保存原件，先确认上次结果，不要重复新建。机器解析、人工核对、正式发布是三件不同的事。目录内容或允许目录策略在预览后改变时，确认同步会拒绝或执行失败，需重新预览。

扫描书籍选择文件时明确拒绝多文件，不再默默忽略其他文件。长书提供有界页码、跳页与待处理筛选。关闭未保存表单会请求确认，不把私人全文自动保存到浏览器持久存储。

## 运行环境边界

本机Python3.14不能安装现有RapidOCR1.4.4（要求Python<3.13）；本轮隔离环境只成功安装锁定PyMuPDF1.26.7，真实DOCX/HTML/PDF内嵌文字与扫描OCR应分别验收。未实测OCR、真实NAS路径或用户资料质量的部分不能用接口fixture通过代替。流程不自动调用云模型、生成知识、审核或发布。
