# 贾维斯 V7 · 三套电影灵感交互原型

打开同目录的 **贾维斯V7.0 · 三套电影灵感交互原型.html** 即可体验。所有样式、动态图形、业务数据和预览图均内嵌；不需要安装依赖或启动服务器。

## 三套方案

| 电影灵感 | 方案 | 主要表达 |
| --- | --- | --- |
| 钢铁侠 | 光核战术台 | 电青与琥珀的全息 HUD；同心反应堆、金属扇叶、棱镜光核和战术扫描 |
| 黑客帝国 | 数字觉醒 | 黑绿终端、流动代码雨、悬浮代码立方体与同心数据环 |
| 漫威 | 赤金装甲舱 | 钢铁侠红金头盔、蓝白发光双眼、漫画分镜与炭黑暖白装甲配色 |

三套采用原创图形。切换时共用同一份模拟业务数据，各套均覆盖语音终端、管理页面与大屏。

## 推荐体验顺序

1. 首次打开直接进入沉浸式对话。顶部切换三种风格；“外观对比”可同时查看三套对话、首页与大屏的实际预览，也可随机抽卡、记下选择。
2. 点击“开始说话”后选择模拟聆听。体验字幕出现、识别请求、整理回应，以及随时打断。也可直接点击“演示这一场景”，或在文字输入区发送。
3. 依次试试语言陪练、讲故事、生活小助手、项目进度和随手记录。右侧展示识别到的意图、使用范围、处理阶段和下一步；相关按钮连接原型中的实际业务视图。
4. 试试“有歧义的指令”：贾维斯会等待你选择开发任务、已部署服务或书籍解析，再展示对应计划。
5. 在“个人档案”中切换家人。各成员拥有独立的会话、记忆、交流设置和学习记录；未知身份进入公共会话，需要个人资料时会等待确认。
6. 打开“管理控制台”或“全部能力”。控制台左侧完整列出当前身份可用的分组功能，并可独立滚动；底部语音、设置与能力目录固定可用。可切换展开导航与图标栏；手机通过抽屉导航访问全部入口。能力目录支持搜索，七类大屏完整保留。

## 保留的完整能力

20 个视图包含：管理总览、语音对话、外部知识接入、知识神殿、原文校对、记忆神殿、专属管家、灵感研究、统一收件、开发监督、项目空间、经验与技能、运行服务、设备管理、家庭安排、个人学习、审批、运维、设置与大屏。

七类大屏包含：集合、家庭、知识、开发、运维、研究、经验。各领域可独立管理，再汇入集合大屏。

知识接入、扫描件校对与发布、知识故事与学习路线、记忆确认和遗忘、灵感转项目、开发任务监督、部署和恢复等流程继承完整原型，三套外观下均可操作。模拟修改保存在当前浏览器；可在设置中导出可见快照或恢复演示。

## 体验边界

这是高保真交互原型。业务结果、意图识别和处理阶段均为模拟，不连接真实机器、模型、知识库或天气服务。浏览器支持时可自行启用麦克风与系统朗读；默认演示无需麦克风权限。系统朗读与自动朗读可分别控制。

动态核心响应聆听、整理、回答、播报、暂停与等待确认等状态。字符场在页面隐藏或核心离屏时停止持续绘制；系统设置减少动画时保留静态视觉与完整操作。

手机以语音主控为先，管理与历史对话按页面继续向下展开。电脑可从语音终端进入管理工作台，再打开各领域大屏。

## 实现文件

最终体验仅需 HTML 文件。`prototype-v7/` 保存分离的视觉与交互源文件；`scripts/build-prototype-v7.mjs` 用于重建单文件。V5 与 V6 版本保留，方便对照与继续迭代。
