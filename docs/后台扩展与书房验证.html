知识原文与解读

原件上传后核验格式、大小和SHA-256，保存在平台数据目录的 knowledge-uploads 中。单件当前支持PDF、PNG或JPEG，最大32MiB；传输接口独立鉴权，没有公开文件地址。

目前人工登记页文，再逐页逐字复核。审核指纹绑定当时的页文；修改页文或增加疑点会使旧审核失效。缺页、未处理疑点和没有有效审核依据的页面不能发布。人工审核不能证明绝对零错；未来OCR接入后仍沿用这些门槛。

故事必须引用已发布版本的指定页原文，解读另行审核。原文修订会使相关故事、课程的旧引用失效，等待复核。资料说明候选只保留原话，不等同扫描原件；转来源后初始停用、未授权。

Pi知识解读使用已发布原文快照，先检查来源有效授权；执行前再次检查，执行期间撤权会请求取消。已经传给供应商的内容无法通过后续撤权撤回，原Pi会话也不因来源撤权自动清除。结果是待人工审阅的草稿，不自动发布或覆盖原文。

Pi后台作业与意图确认

Pi SDK仍为1.0.2。新增后台作业使用专用Pi会话，平台同时处理一项，单轮最长180秒；关闭业务查询工具、SDK自动重试和自动压缩。每项最多提交一轮提示，不承诺供应商内部请求次数或实际费用。目标最多12,000字，来源上下文最多16,000字，大部头需要分段分析。

作业保留来源修订和输入快照。来源在分析中更新，结果标记需要重新核对，不写回研究证据或知识结论。取消会记录状态并调用Pi原生中止；重启后运行中的作业标为中断，不自动付费重试。

对话页“理解任务”：核对文字 → Pi提出最多三个选项 → 本人明确确认 → 保存回执。当前只允许继续对话、保存一条灵感收件、建立待讨论研究记录；未确认不创建业务记录，不能通过模型输出派发开发、部署或删除。实际动作说明由后台固定生成。

对话的11个只读工具可查询项目、设备、任务、经验、收件、研究、交付、有效授权的已发布知识、本人确认记忆、家庭共同待办和服务台账。不会查询其他家人的私人记忆或健康备忘。

成员、记忆与运维边界

家庭档案登记成功后可独立配置声音和唤醒词，但不是家人的登录凭证；切换档案不改变管理员身份。当前只有管理员本人可使用真实私人会话、记忆和健康备忘，其他家庭成员需要后续独立认证。

遗忘会移除这条记忆的正文、来源、历史正文以及旧幂等回执里的正文，保留最小遗忘状态。原始聊天、收件、Pi JSONL和既有备份独立保存，不属于这次逐条遗忘的清除范围。留存策略现在保存请求意向，定期清理和自动记忆提取仍待接入。

设备在线、服务健康、发布成功、备份完成和恢复成功都不能仅凭人工登记推导为平台执行。部署审批绑定具体申请；批准后不会远程执行，目标设备或环境变化后旧批准不能继续使用。

设置中的暂停开关只阻止新Pi作业提交和排队启动，不中断既有作业或外部开发进程；运行中作业可逐项停止。每日预算与任务重试值目前为参考，未接入实际模型成本拦截。策略部分更新会保留未修改字段，避免意外解除暂停。

本地备份脚本现在包含业务SQLite、Pi专用资料及真实知识原件目录；停止后端后再备份，备份目录限制当前用户和SYSTEM访问。界面的外部备份证据登记与这个本机备份脚本是两个明确入口。

验证与使用顺序

  1. 在书房联想打开完整平台，登记成员、设备、服务和房间入口，验证刷新及重启后的记录。
  2. 配置Pi并验证文本对话、单轮研究、意图选择与打断；真实供应商的联网和实际语音效果需要现场测试。
  3. 上传小规模原件，逐页登记、校对、发布，验证故事引用、课程、记忆确认和遗忘。
  4. 接通中央语音后，在联想书房完成按键语音、唤醒、回声处理与播放中打断。
  5. 通过后部署到48GB主机，验证HTTPS、设备配对、备份恢复和书房浏览器客户端；然后逐个测试其他房间。

本轮自动验收使用临时数据库、临时原件及离线／FakePi，不请求实际付费模型，不向真实服务器发布；验收业务写入均在临时库完成。
