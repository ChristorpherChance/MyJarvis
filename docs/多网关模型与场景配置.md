## 从哪里配置

打开[系统设置 → 模型中心](https://cc-jarvis.ikvein.com/?mode=platform#theme=stark&view=settings/models)，也可在对话页点击“模型配置”。

- **场景分配**：选择每个场景的服务与模型，统一保存。沿用默认的场景随默认模型变化；独立选择的场景保持自己的配置。
- **模型服务**：接入或更新网关、读取真实模型目录、设置默认模型、验证选中的模型。点“仅保存服务”不会切换默认模型。
- **用量价格**：按网关实际报价填写输入、输出、缓存读取和缓存写入价格，单位为美元 / 百万 Token。免费项需明确填 0。

当前默认保留 **SuperOpen / CPA / gpt-6.1-sol**。初始场景均沿用默认；验收时临时分配的测试配置已恢复，不替用户决定生产场景的模型。

## 已接入的服务

| 服务 | 地址 | 模型目录 | 实际验证 |
| --- | --- | --- | --- |
| SuperOpen 网关 | https://gw.superopen.top | 9 个 | 已验证真实流式对话、只读功耗查询与会话保存 |
| IKVein 网关 | https://cc-gateway.ikvein.com | 6 个 | Kimi K3、DeepSeek V4 Flash 均通过 Pi SDK 最小对话测试；家庭对话入口通过 Kimi 场景分配测试 |

IKVein 实际目录：Kimi-Coding/k3、Kimi-Coding/kimi-for-coding、Kimi-Coding/kimi-for-coding-highspeed、Kimi-Coding/k3-256k、DeepSeek/deepseek-v4-pro、DeepSeek/deepseek-v4-flash。目录名称来自网关；其他四个型号尚未逐一发起真实对话验收。

两套网关均提供 Claude 兼容的 messages 接口，通过 Pi 原生模型配置与登录保存接入。SuperOpen 的已验证显示命名空间转换保持原有规则；IKVein 保留其原始模型编号。不能据目录名称确认底层模型的厂商身份或性能。

以后可添加新的 HTTPS 网关，选择 Claude 兼容 messages 或 Chat Completions 兼容协议。每个网关独立编号、凭据和模型目录，最多 128 个网关。已接入编号的地址与协议固定，变更地址需新建服务，避免把原密钥发送到新目的地。目录读取不跟随重定向。

网关未返回上下文长度、视觉和推理等能力元数据，当前使用保守的纯文本配置：32,768 上下文、4,096 最大输出。模型名称中的“256k”等字样不作为已核验能力。

## 九类场景对应哪些实际调用

| 场景 | 接入入口 | 边界 |
| --- | --- | --- |
| 管家对话 | 管理员流式对话、只读平台查询 | 操作另行授权，不因换模型增加权限 |
| 家庭对话 | 成员对话、房间语音对话中的文字理解 | 每个身份的聊天和工具仍独立 |
| 意图理解 | 语音原话分析、兼容意图作业 | 输出待确认选项，不直接执行 |
| 学习陪伴 | 语言陪练、知识教学和食谱提案 | 当前只验证文本教学，不伪造发音评分 |
| 知识整理 | 校对后的原文解读、故事、课程候选和兼容知识作业 | 原文与候选仍需独立人工审核 |
| 记忆整理 | 本人原话提取长期记忆候选 | 隐私、证据与确认策略继续执行 |
| 深度研究 | Pi 研究作业、证据与方案分析 | 不自动采纳或发布结果 |
| 项目开发 | Pi 项目执行器 | 独立验收、项目目录与预算约束保持生效 |
| 通用作业 | 未单独归类的有边界智能作业 | 无业务操作工具、无自动重试 |

语音识别 ASR、声音合成 TTS、唤醒与扫描件 OCR 属于独立引擎，继续在“运行引擎”中配置。外部 Claude Code / Codex 执行器自身的模型配置也独立，本页不向所有服务器分发网关密钥。

## 隐私、价格与运行规则

场景来自服务器固定调用入口，家庭请求不能自行指定模型、引擎或身份。成员“仅本地”偏好检查实际场景模型及认证地址，外部网关不会被当成本地；切换模型不绕过单次云端同意。

密钥仅由 Pi 原生登录保存在 112 私有认证目录，不出现在模型配置、接口响应、浏览器存储或验收报告。临时 cc-gateway-api-key.txt 已在保存和真实验证后删除。新网关保留原默认服务的凭据，重启后可继续使用。

两套网关未提供价格，目前按实际返回记录 Token，费用为未定价，不能当成免费。需要费用预算的后台作业在模型未定价时拒绝执行；填写并确认价格后可用于估算与预算控制。估算不等于服务商账单，也不追溯改写历史未知费用。

配置使用版本检查，旧页面不能覆盖新配置。有 Pi 对话运行时暂缓保存；下一轮调用使用新配置。已指定模型失效时明确报错，不静默换服务。模型目录更新会保护已被默认或场景引用的型号。

## 验收与接口

已通过场景真实 SDK 路由、认证持久化、并发修改拒绝、过期版本、隐私拒绝、未知价格拒绝、人工价格估算和开发模型选择检查。HTTP 接口验证管理员认证及类型契约；完整应用回归覆盖语音、成员、知识、记忆与预算；Linux 隔离启动和冷备拒绝启动检查通过。

生产浏览器已验证 9 类场景的保存与重载、15 个网关模型、密钥留空不回显、家庭对话实际使用指定 Kimi 模型及按场景记录用量、价格留空。临时路由已恢复。电脑与手机布局分别检查，十套主题的实际主题属性和样式文件单独验收。

| 接口 | 用途 |
| --- | --- |
| GET /api/settings/pi | 默认模型、服务、凭据状态、场景及价格配置 |
| PUT /api/settings/pi | 保存默认模型与原生认证 |
| POST /api/settings/pi/gateway/discover | 向指定网关读取模型目录 |
| POST /api/settings/pi/gateways | 独立接入或更新网关，不切换默认模型 |
| PUT /api/settings/pi/routing | 按版本保存完整场景覆盖表 |
| PUT /api/settings/pi/pricing | 按版本保存或清除模型价格 |
| POST /api/settings/pi/test | 测试指定模型或已生效场景，不携带业务查询工具 |

验收记录：artifacts/model-routing/gateway-connection.json、artifacts/model-routing/ui/report.json、artifacts/model-routing/ui/layout-report.json。全平台契约现登记 355 项真实路由操作。
