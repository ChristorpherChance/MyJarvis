# 中央语音与任务通知接入

更新日期：2026-10-06

本文保留20261006-conversation阶段的接入说明。当前已发布20261006-companion，语言陪练、分步食谱及持久计时已接入，原表中的这两项待开发状态已更新；最新实现、常驻状态与剩余能力请看[常驻修复与家庭陪练接入](常驻修复与家庭陪练接入.md)。

本轮将管理端和房间端的语音入口接入中央语音服务，补齐“听懂需求 → 给出选项 → 本人确认 → 保存事项 → 到期通知”的流程，并接入真实天气。本文说明当前代码实现范围、配置方法和仍待完成的能力。最终构建、接口总数与整体测试统计以本轮验收报告为准。

## 1. 这次接入了什么

| 能力 | 当前实现 | 使用条件 |
| --- | --- | --- |
| 中央语音 | 浏览器录音上传，中央 ASR 识别；Pi 对话后中央 TTS 合成，再由浏览器播放 | 配置可用的 ASR、TTS 与 Pi 模型；麦克风可用 |
| 语音事项 | 根据真实识别结果提出冻结选项；口头或点击确认后创建记录 | 有效本人登录、当前会话与识别轮次；明确选择 |
| 主动通知 | 服务端持久通知、本人偏好、静默时段、去重、到期提醒；房间中央合成与播放回执 | 房间播报需本人明确开启、有效配对终端、会话空闲、预算允许 |
| 真实天气 | 城市搜索、个人/家庭共同城市、天气查询、明确缓存状态；Pi 可查询天气 | 管理员启用天气服务，先选择城市，服务端可访问提供商 |

当前联想 64GB 笔记本用于开发和书房验证。后续迁移到 48GB 服务器时，平台、数据库、调度与接口由该服务器运行；房间浏览器负责录音、展示、播放和回报状态。高算力语音引擎可以通过中央 HTTP 接口独立配置，房间终端无需运行模型。

## 2. 中央 ASR / TTS

### 已实现的链路

1. 管理对话页或房间入口取得麦克风权限并录制实际音频。
2. 音频上传到中央语音会话，服务端调用配置的 ASR 引擎并返回真实任务状态与识别文本。
3. 普通聊天使用 Pi；需要保存事项时进入选项确认流程。
4. 回答文本由中央 TTS 引擎合成。浏览器下载中央音频并播放。
5. 播放开始、结束、打断和浏览器阻止播放分别记录为客户端回执。

ASR / TTS 支持受控命令适配器和 HTTP 适配器。HTTP 适配器用于对接可用的语音服务；命令适配器执行管理员配置的固定程序与参数。未配置或引擎失败时显示真实错误，不用动画代替识别或合成结果。

### 已有约束

- 语音任务绑定登录成员、会话和对话轮次；旧轮次音频不能继续当作当前回答。
- 成员语言、声音映射、语速与语音偏好独立保存。
- 打断、取消、静音或身份失效会阻止旧任务继续交付。
- 云端调用同时受本人云端策略和明确同意约束；中央用量与预算门禁继续生效。
- 实际解码音频时长用于语音分钟额度，不把文件体积当作时长。
- 原始音频保留按成员策略处理；浏览器播放回执不能证明物理扬声器已经发声。

### 书房接通步骤

1. 在管理设置中配置 ASR、TTS，并检查 Pi 模型认证与用量策略。
2. 在联想笔记本管理对话页完成一次录音、识别、回答、合成和播放。
3. 为书房入口配对终端，使用家庭成员凭据登录房间页面。
4. 分别检查多人隔离、打断、静音、浏览器阻止自动播放和断线恢复。
5. 书房通过后，再迁移中央服务至 48GB 机器并接入其他房间。

浏览器麦克风通常需要 localhost 或 HTTPS。局域网其他设备访问服务器时，需要配置可信的 HTTPS；页面打开不等于麦克风权限已经可用。

## 3. 听懂事项后，让本人作决定

房间入口使用当前会话真实完成的 ASR 结果进行意图分析。Pi 只能提出有限选项，服务端校验动作、内容、范围、时间和数量，并将选项冻结。分析阶段不创建业务记录。

### 当前可确认的五类事项

| 事项 | 确认后的结果 |
| --- | --- |
| 收件记录 | 保存本人私人收件，保留内容，不启动开发 |
| 候选记忆 | 保存本人候选记忆；进入长期记忆仍需复核 |
| 家庭待办 | 创建全家可见的共同待办；不控制设备 |
| 研究记录 | 新建待讨论研究；不自动启动研究或开发 |
| 定时提醒 | 按明确时间创建本人提醒；遵守本人通知偏好 |

系统读出选项内容、共享范围及作用。可以说“确认第一项”“确认第二项”“确认第三项”或“取消”，也可以点击对应按钮。模糊表达会继续请本人明确选择；不会把普通“好”直接当作操作批准。

提醒必须有明确的未来时间，且在确认时读出时间。时间不清楚时需要继续澄清，不猜测日期。模型提出选项不能开启云端权限、共享私人记忆、发布服务、关机或替代开发验收。

选项绑定原成员、登录会话、房间与当前识别轮次，具有有效期和修订版本。重复确认返回原记录，不重复创建；取消和过期后不能重新执行。

## 4. 主动通知与房间播报

### 通知来自真实事项

通知调度扫描实际业务记录，包括任务阻塞与逾期、待审批、真实健康探测异常、研究待决策、原文待校对、知识来源异常、课程来源修订、待确认记忆、收件待整理、恢复演练失败和到期待办。明确创建的提醒也由调度按时间触发。

同一事项在同一个异常阶段只产生一条通知；恢复后再次异常可以形成新通知。通知、已读、确认、投递租约与回执持久保存，平台重启后仍可查询。

### 本人偏好

每位成员在服务端独立保存：

- 是否主动提醒，以及任务、服务、研究、知识、学习、备份、提醒、记忆分类开关。
- 站内提醒、前台浏览器通知、房间主动播报的渠道。
- 安静时间、时区及是否允许通知合成使用云端。

保存需要当前修订版本，避免多端互相覆盖。关闭主动提醒仍可主动打开本人通知中心查看。通知“确认收到”不会完成原任务或批准原审批。

### 三种渠道的实际含义

| 渠道 | 当前能力 | 真实边界 |
| --- | --- | --- |
| 站内通知 | 本人通知中心与在线页面轮询，未读、已读和确认持久保存 | 页面/平台需要在线 |
| 浏览器通知 | 本人点击授权后，前台页面调用浏览器 Notification API，并记录实际呈现、点击或阻止回执 | 尚无离线 Web Push；关闭页面不保证收到 |
| 房间播报 | 已配对浏览器在空闲时领取一条通知，中央 TTS 合成、下载音频、播放并上报实际事件 | 本人明确开启；成员和终端有效；安静时间、静音、预算、云策略都允许 |

私有或公司事项在房间只播报泛化提示，例如“你有一条到期提醒，请在本人通知中心查看详情”。全家共享事项才可播共享正文。管理者切换展示档案不会获得其他成员的私人通知。

房间领取采用短租约、防重请求和一次自动投递策略。领取请求断开会取消合成；关闭平台、租约过期或播放结果不明确时标记未知/中断，不伪称成功，也不自动再次播同一条。事项仍留在通知中心供本人处理。

浏览器提供的“已开始”“已结束”“被阻止”都是客户端报告，不代表服务器检测到了真实扬声器声音。未配置邮箱和离线推送时，不显示“已发送”或“已投递”。

### 建议先这样使用

先开启站内提醒，完成书房本人身份和语音闭环后，再由各成员自行开启房间播报。安静时间按成员设置；共享屏幕和无人值守房间入口不主动展示私人正文。

## 5. 真实天气

天气采用 Open-Meteo / GeoNames 查询。城市由本人搜索后明确选择；管理员可设置家庭共同城市。未设置城市时会提示选择，不根据聊天或设备位置自行推测家庭地址。

- 本人城市只在本人认证空间使用；公共展示和共享交流使用家庭共同城市。
- 支持当前温度、体感、湿度、风速、天气描述和未来天气。
- 卡片展示天气时间、查询时间、时区、数据来源以及缓存状态。
- 提供商失败时只在配置的期限内显示旧缓存，并明确标记缓存时间；没有可用数据时直接显示不可用。
- 只向天气提供商发送搜索词或城市坐标，不发送成员身份、对话、记忆或通知内容。
- 查询有超时、短期频率和本机每日请求上限；设置和城市偏好也采用修订版本防覆盖。

天气属于提供商的天气模型数据，不等于家庭现场传感器实测。服务来源、许可和商业使用限制在设置页展示；免费服务的可用性不由本平台保证。

## 6. 费用和运维大屏

运维大屏已读取服务端治理用量，显示 USD 估算、实际报告用量与未回报项目，不把 USD 随意换算成人民币。费用依据真实 SDK / CLI / 语音用量及已配置计价来源；没有可定价或厂商账单时保留未知，不写成 0 元。

通知语音继续经过统一预算门禁。预算不足会暂缓领取，不消耗该事项的一次自动播报机会；合成或播放失败保留真实失败状态和待处理事项。

| 48GB 生产迁移 | 当前仍是联想开发/验证阶段；最终服务安装、HTTPS、备份排程与房间实测属于部署验收 |

## 8. 本轮验证方式

新增通知专项使用临时数据库、真实 HTTP 请求和隔离身份，语音引擎为可控测试适配器。覆盖持久化与去重、成员隔离、偏好修订、静默时段、预算拒绝、私人正文脱敏、重启防重、明确提醒、身份撤销、真实连接断开、浏览器呈现回执和实际播放事件顺序。

这些测试没有修改正式数据库，没有调用收费模型，没有发送邮件/短信，也没有改变真实机器电源或发布环境。中央语音、口头确认、天气和全平台最终验收记录由主集成报告补充。
