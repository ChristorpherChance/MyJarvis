# V14 页面文案与操作清单

范围：18 个功能页；总览、大屏内容和导航由对应模块负责。顶部当前页面名称同步全部 20 个路由的四字导航名，按身份显示家庭资料/个人设置。对话保持 V13 的左右分区。仅修改界面标题、静态说明与操作标签；不改故事、聊天、私人记忆、原文、数据或权限规则。

| 页面 | 统一标题 | 一句话目的 | 主要操作与保留的信息 |
| --- | --- | --- | --- |
| chat | 语音对话 | 直接说话，也可输入文字 | 开始说话、打断、输入、场景与识别面板；敏感指令仍需确认 |
| inbox | 统一收件 | 汇总记录，分类归档并保留原话 | 快速记录、语音记录、采集范围、重复合并与处理 |
| research | 灵感研究 | 记录想法，核对证据后决定是否立项 | 新建灵感、研究边界、证据、反证、方案和人工决定 |
| projects | 项目管理 | 管理项目目标、工作副本和交付结果 | 新建项目、详情、目标验收、工作副本和关联任务 |
| tasks | 开发监督 | 查看执行进度，处理阻塞与验收 | 新建任务、监督开关、急停、暂停/恢复、只读会话边界 |
| knowledge | 经验技能 / 家庭资料 | 记录经验，验证后发布可复用技能 | 记录经验、验证发布、版本复用；家人进入家庭资料，私人记录仅本人可见 |
| sources | 知识接入 | 接入知识来源，管理授权与同步 | 接入来源、配置、同步、启停和联合检索；授权先于检索 |
| temple | 知识神殿 | 按故事、主题与课程学习，随时查看出处 | 上传扫描、学习故事、关系图、课程和补充建议；原文版本与出处保留 |
| collation | 原文校对 | 处理识别疑点，逐页复核后发布原文 | 上传扫描、人工裁决、逐页复核、发布和修订；发布门槛直接显示 |
| learning | 学习计划 | 查看我的学习记录与练习计划 | 开始口语、历史、科学练习及学习偏好 |
| family | 家庭安排 | 安排共同事项，继续学习与生活交流 | 首排天气、学习、共同事项；生活帮助随后；做菜、健康备忘和身份切换保留；家庭成员可展开 |
| memory | 记忆神殿 | 我的私人记忆，可随时修改或遗忘 | 新增记忆、确认候选、编辑、遗忘、保存策略和导出 |
| personas | 专属管家 | 设置我的声音、唤醒词和交流习惯 | 页头保存设置、试听、切换本人档案；声线不赋予权限 |
| machines | 设备管理 | 查看设备状态、用途和项目副本 | 登记设备、筛选、搜索、详情、唤醒和用途调整；待核实硬件不改写 |
| services | 运行服务 | 查看服务健康，管理版本与部署 | 登记服务、交付包、部署审批、验证和恢复；公司范围只读 |
| operations | 运维费用 | 查看运行健康、预算、备份与用量 | 调整预算、备份、恢复演练和用量；演示费用不冒充实际账单 |
| approvals | 待办审批 | 核对变更、备份和恢复方案，再决定 | 逐项查看、批准、拒绝和审计；高风险二次确认保留 |
| settings | 系统设置 / 个人设置 | 调整外观、语音、隐私和运行策略 | 设置开关、预算、导出和重置；家庭成员不出现管理选项 |

实现约束：只修改现存节点的精确静态文本，保留按钮的动作、表单名、输入值、节点身份和事件。长篇背景说明收进可展开的说明；权限、发布门槛、执行影响不收起。列表自然增长，不用固定高度裁掉数据。正文与表格使用 14 px，辅助标签至少 13 px。
