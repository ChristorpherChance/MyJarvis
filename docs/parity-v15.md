# V15 功能与交互恢复清单

验收基线：`贾维斯V15.0 · 十套主题与全平台交互原型.html`。本清单来自实际成品及其构建链：V5 业务基座、V14 导航/文案/大屏、V13 对话分栏、V15 图形与主题特效。用于逐项恢复正式前端，不能以「首期」为由删掉原型中已确认的入口与交互。真实后台尚未接入的功能必须明确显示为演示，不能把模拟进度、模拟设备在线或手工状态伪装成真实监督结果。

## 逐页验收

### overview · 总览中心

- 首屏四环形指标：设备、任务、服务、审批，使用当前记录计算；没有真实历史就不能生成伪趋势。
- 六域图可点选、键盘聚焦、显示关联说明；中心贾维斯进入语音。设备矩阵与领域视图切换，资产卡进入设备详情，公司 HP 保持只读。
- 优先任务展示状态、进度依据和处理入口；重点待办与审批数分开；疑点、补充、服务异常及备份提醒能跳到对应具体记录。
- 家庭/公共身份只呈现授权信息；1366×768 优先重点一屏，窄屏自然排列。

### chat · 语音对话

- 六场景：轻松聊聊、语言陪练、听故事、生活助手、项目进度、随口记录。七状态：ready / listening / thinking / speaking / interrupted / answered / awaiting。
- 场景图像左侧约 75%，内容及控制右侧约 25%；普通与沉浸模式都保留该分栏，沉浸隐藏导航及杂项，窄屏堆叠。十主题必须使用各自真实视觉和状态特效。
- 可编辑字幕、输入发送、Enter 发送/Shift+Enter 换行、模拟识别、结束一句、打断停止、场景演示、有歧义指令演示。真实麦克风只在浏览器支持、本人授权及处理路径已说明后启用；演示明确标识未采集声音。
- 身份未知不读取私人聊天、记忆、健康及公司/开发数据。切换人时停止朗读、识别、延迟回答和待确认命令，个人会话隔离。
- 新会话有确认；文字不保存策略用临时会话；保留策略可查看。朗读最新回答、试听声线、停止播放只在用户主动启用后执行。
- 回答带关联操作：故事来源/小测/路线、语言完成/学习摘要、记录分类至统一收件、具体项目进度、个人记忆候选。歧义指令先选择开发/服务/书籍等对象，再展示对象、影响、预算、恢复办法，明确确认才生成计划，不能聊天自动执行。

### screen · 大屏中心

- 七屏切换、全屏/退出、时钟、按现有记录联动、具体事项进入业务页，个人/公共可见范围正确。
- all 全域总控：六域图、设备矩阵、四指标、任务泳道、重点事项。
- family 家庭与语音：共享待办完成度、主题语音入口、练习与故事、示例天气；自己的学习可见，健康/私人记忆不在家庭屏展示。
- knowledge 知识与故事：原文阶段、关键疑点、补充建议、主题分布及书目；异常数量不是顺序处理阶段。
- development AI研发：真实状态分类、卡住原因、验收证据、交付版本；计划→执行→验证→交付关联。
- operations 运维运行：健康来源、未检查/异常/离线、保留配额而非虚构 CPU 历史、部署与恢复结果；配额冲突可见。
- research 灵感研究：支持/反证/未知证据分别计数、阶段、待决定方案；不得将数量写成可信度评分。
- experience 经验技能：记录/已验证/发布 Skill/复用是不同单位；记录→验证→固定版本→反馈可追踪。

### inbox · 统一收件

- 待整理、重复、已处理、全部筛选；手工/语音快速记录保留原文、所有者、终端、时间、类型、范围和项目。
- 灵感/经验/教训/Skill/个人记忆/书籍材料分类；私人、家庭、公司边界；详情、编辑、忽略、去重合并或保留独立。
- 分流至研究、经验、记忆候选、知识材料，并可打开实际目标。被动采集选设备/项目/字段和开关，示例事件必须说明为演示。

### research · 灵感研究

- 四筛选与检索；原始表达保持不变。目标与讨论、证据与反证、方案与决策、研究轨迹四详情页签。
- 研究问题、标准、假设、补充讨论；节点/时间/预算/重试/停止条件；暂停、继续、阻塞、配额等待和失败演示。
- 支持/反证/未知证据保存出处、定位和核实状态；来源详情、添加/移除候选。方案比较投入、成本、收益、风险及推荐依据。
- 接受/暂缓/否决都有理由；只有明确接受方案后才建立项目并确认目标、仓库、验收和节点，研究完成不能自动变成项目。

### projects · 项目管理

- 分类、检索、新建；总览、任务产出、工作副本、关联经验四详情页签。
- 目标、描述、仓库、范围、阶段、里程碑和进度依据；任务创建、证据、经验关联与整理。
- 多机器副本记录路径/分支、添加/删除登记、与设备详情双向关联；环境信息可编辑；托管剩余里程碑先具体确认计划。

### tasks · 开发监督

- 四状态筛选、列表/看板；新任务区分只观察/托管，Claude Code/Codex/其他执行器、项目、节点、目标、验收、预算、时间、重试、工作区/会话。
- 计划验收、执行事件、变更产出、使用 Skill、监督策略五页签；事件/测试/产出有来源和时间，Skill 固定版本。
- 自动监督开关、紧急停止与解除、暂停/继续/阻塞处理/取消、配额/等待审批/离线原因；只观察会话不能直接控制。
- 手动暂停持续有效；任务已验收必须有符合标准的证据和交付说明，不能靠定时百分比假完成；可导出验收摘要及转为经验。

### knowledge · 经验技能

- 问题经验、通用 Skill、操作手册、家庭知识四页签；范围和授权正确；检索正文/标签，新增、编辑、完整详情、来源和 Markdown 导出。
- 验证经验、相似合并、验证后生成 Skill 草稿；发布/弃用/新版本/版本快照，任务使用冻结版本并记录效果。
- 使用次数、失败反馈、项目/机器来源、附件、恢复演练、私人记录删除确认；家庭知识不能泄露公司资料。

### sources · 知识接入

- 来源列表、联合检索、同步状态三页签；可持续添加不同连接类型与本地/在线/混合模式、主题、权限、范围、版本、同步策略和授权。
- 配置/同步/启停/撤销授权；撤销后立即排除检索。联合检索只返回授权且已发布内容，并注明来源、版本；失败来源与部分结果明示。
- 同步日志、失败恢复、并发配额、连接方式均可看及演示。

### temple · 知识神殿

- 独立故事、知识脉络、我的课程、书目原文、补充建议五页签；最后一项为管理者。
- 扫描上传、版本/阶段、不可变原件/校对基库/解读衍生层；出处定位到版本、页及块。故事听读、来源、小测、收藏、等级/时长/主题，未发布或失效内容不可学习。
- 可点击关联图连接人物、时代、学科与出处；故事独立且可在多条课程复用。主题/书目/人物生成个人路线，进度、启动、版本刷新和移除。
- 补充建议包含缺口、理由、预期改善和优先级；接受/暂缓/忽略，接受生成补充请求而非自动采用任意来源；收件材料可进入书目草稿。

### collation · 原文校对

- 书籍队列及当前书；疑点裁决、逐页精校、版本修订、校对日志。
- 文件指纹、页码/顺序、布局与解析通道、阶段、有限 OCR 演示；原页/局部图与候选逐项对照，选择/手工修正/无法辨认需重扫。
- 逐页确认及重要疑点阻断发布；全卷复核只是演示不能声称 AI 已保证零错误。发布校验原件完整、关键疑点清零、人工复核及版本。
- 新版本修订理由、旧版本查看、决策审计；相关故事标记需重解读、个人课程提醒刷新版本。

### learning · 学习计划

- 当前人语言/等级/节奏/纠错偏好，今日口语、历史、科学等学习卡，最近记录。
- 逐轮练习、纠错复习、理解提问/小测；个人分钟/完成/活跃天数/分数和记录；与语音对话、正式故事课程双向跳转。

### family · 家庭安排

- 共享待办显眼可新增/完成/移除、日期及提醒；日程、示例三日天气、自己的学习继续和进度。
- 日常聊天、语言、历史/科学、烹饪、健康入口；成员折叠卡和本人空间选择。健康作为本人私人备忘，不进入家庭屏。
- 菜谱人数/口味、逐步指导、朗读、下一步/完成、计时暂停/继续/复位；个人语言逐轮与故事路线可完成并归档学习。

### memory · 记忆神殿

- 已确认、待确认、遗忘与拒绝三页签；新增内容/类别/时效/来源/性质及本人范围。
- 候选确认/拒绝，编辑、遗忘确认，来源和修订历史，导出本人记忆；遗忘移除正文及旧正文版本但保留必要事件元信息，原聊天/收件另行处理。
- 文字 never/7/30/forever、音频 never/session/7、长期记忆 confirm/explicit/auto 三项策略；未接存储作业就不能声称实际音频已清理。管理员身份不自动获得他人私人正文。

### personas · 专属管家

- 本人模拟档案切换，取消识别/播放/待确认；声线和唤醒词不能当授权凭证。
- address、wakeword、voice、language、pace、replyStyle、privacy、dailyVoice、quietStart、quietEnd、autoSpeak 全字段；页面主保存按钮、未保存修改试听、返回语音。
- 试听实际设备浏览器声线，只经本人点击，可停止；云端 ask/local/allowed 偏好及降级说明，不自动上传音频。

### machines · 设备管理

- 原型 21 资产、四状态/常开筛选、搜索、网格/列表、真实未知字段和最后上报时间；登记及角色/开机策略编辑。
- 物理 CPU/内存/硬盘/GPU/系统、最后已知状态；工作副本路径分支、关联任务、服务、备份、功耗，双向关联项目。
- 唤醒/休眠为演示；公司 HP 只读且不参与自动任务调度。

### services · 运行服务

- 运行服务、交付包、部署记录三页签；新增编辑服务关联机器/环境/项目/地址/进程服务容器、健康源、版本、启动、备份恢复与只读范围。
- 详情、健康刷新、事件与故障演示；交付包来自已验收任务，含测试、构建产物、配置及回滚；版本来源可追溯。
- 部署请求固定环境及版本，展示影响/备份/恢复，再审批→执行→健康验证；失败→恢复→恢复验证→回执，不能只改成功状态。只读服务阻止控制。

### operations · 运维费用

- 今日成本/日预算、节点健康/功耗、最近演练、周成本图；演示成本与真实计费分开。
- 运行检查、备份与版本、恢复演练、导出、NAS 入口；人工/语音资源保留、批处理上限、安静时间、监督、自动唤醒、通知。
- 按任务/通道/预算的使用和受限原因、联动任务；无实际来源不声称真实用量/账单。

### approvals · 待办审批

- 待审批、已处理、审计日志；详情风险、对象、项目/节点、固定版本、变化、范围、影响、备份和恢复。
- 接受/拒绝、L3 二次确认、相关任务/部署流程；已处理决定不可覆盖历史，审计有时间与对象；只读权限不允许控制。

### settings · 系统设置

- 外观模型、监督预算、身份隐私、通知语音、演示数据五页签；十主题画廊、每主题对话/总览/大屏预览、选择/进入/随机抽卡，保存选择；深浅切换记住对应主题。
- 模型本地/云端与降级、学习偏好；监督/唤醒/预算/重试/紧急停止；本人记忆策略和公司只读提示。
- 有意义的通知、安静时间、语音开关；按权限导出演示快照、重置二次确认，明确不修改真实后台数据。

## 原正式前端缺口与恢复状态

盘点时 `apps/web` 只有 overview/devices/projects/tasks/experiences/chat/members/settings 八个简单页面；其中 devices/experiences/members 也不能替代 machines/knowledge/personas 完整功能。缺统一收件、研究、七大屏、外接来源、原文校对、知识脉络、课程、家庭安排、个人记忆、运行服务、部署、审批、运维预算等入口。现有项目/任务缺四/五详情页签与关联流程；文本 Pi 对话缺六场景、语音状态、沉浸分栏和主题视觉；成员表单缺完整专属管家字段；设置缺完整五页签与画廊。

恢复须逐页核对本清单，保持真实数据与演示数据互不冒充。需要后台能力才能落地的环节，先补完整可交互演示及能力状态，并为将来的连接保留字段与真实来源，而不是删除界面。确实无法使用或逻辑不成立的原功能，列出具体证据交用户决定，不自行移除。

## 端到端验收流程

1. 灵感快速记录→收件分类→研究证据/方案→接受决策→项目→托管任务→事件/验证→交付→审批→部署→健康/恢复回执。
2. 问题经验→验证→Skill 草稿→发布版本→任务绑定固定版本→效果/失败反馈→新版或弃用。
3. 扫描书籍→解析疑点→逐页校对→人工复核→原文发布→故事及出处→知识关系→个人课程→语音听讲/小测→个人记录；修订后衍生及课程版本提醒。
4. 语音轻松聊/陪练/故事/生活/进度/记录→正确字幕状态→打断→歧义选对象→确认计划；新会话、公共身份、档案切换没有跨人残留。
5. 本人记忆候选→确认/拒绝→编辑→来源历史→遗忘→正文及旧副本移除；本人导出及保留策略；家庭屏始终不展示私人健康/记忆。
6. 十主题逐一检查对话、总览、七大屏、列表、弹窗及移动端；对话左75%右25%、沉浸只剩对话舞台与控制；总览/大屏桌面重点尽量一屏，允许必要窄屏滚动。
