连接和开始开发

在当前联想电脑的 PowerShell 或 Windows Terminal 中：

ssh 112
# 同样支持：ssh jarvis-112

这两个别名沿用原 112 专用 SSH 密钥及固定主机指纹，保留原有其他连接配置。其他电脑可使用其已有登录方式连接：

ssh superopen@192.168.10.112

进入 112 后创建或进入自己的项目目录，再启动 AI：

cd ~/All-Projects
mkdir -p my-project
cd my-project
claude

也可以先用 git clone 获取仓库。私有仓库所需的 Git 身份、凭据和授权需按该仓库已有方式配置；本轮没有迁移 Git 私钥或 GitHub 登录态。

Claude Code 是终端客户端。当前默认使用既有 JP-CCR (Codex订阅) 通道，请求模型 gpt-6.1-sol[1M]；实际回执的标准化模型名为 gpt-6.1-sol[1m]。不把客户端名称当成底层模型厂商。

切换模型通道

ccswitch
# 同样支持：cc-switch

# 查看 Claude 的通道列表
cc-switch --app claude provider list

# 按唯一名称或 ID 切换；在新 Claude 会话中生效
cc-switch --app claude provider switch 'JP-CCR (Codex订阅)'

终端界面可用 Ctrl+C 退出；主页的 Q/Esc 会进入返回或退出确认流程。

服务器安装的是 CC Switch 桌面项目推荐的社区终端版，适合 SSH；无需启动图形桌面。上游说明 · 固定版本 v5.11.2。

已导入本机现有的 9 个 Claude API 配置：AIGoCode、Kimi For Coding、Xiaomi MiMo、Xiaomi MiMo plan、My Claude、DeepSeek、AIGoCode copy、Kimi For Coding-699、JP-CCR (Codex订阅)。只迁移连接和模型字段；未迁移本机 hooks、插件、状态栏脚本、聊天或浏览器登录态。其余 8 个通道没有逐一发起真实模型调用，余额、可用性和计价均待实际使用确认。

断线后继续

已创建空闲的 ai-dev tmux 会话，工作目录为 ~/All-Projects，没有在后台启动 AI：

tmux new -As ai-dev
# 在 tmux 中进入项目目录，再运行 claude

按 Ctrl+B，松开后按 D，可暂时离开会话；下次登录后再执行同一条命令继续。需要找回 Claude 之前的对话时，在对应项目目录执行 claude --continue，或使用 claude --resume 选择历史会话。
