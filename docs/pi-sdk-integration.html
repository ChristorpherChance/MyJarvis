十一个只读查询工具

工具查询来源与边界
jarvis_projects原 S0 台账与 V1 真实项目；登记路径不表示已读取仓库
jarvis_devices本机采样与已登记设备；其他机器未接入 Agent 时状态未知
jarvis_tasks原 S0 台账与 V1 任务；人工报告不表示已派发执行或独立核验
jarvis_experiences原 S0 与 V1 经验、技能；不读取家庭私人聊天
jarvis_inbox当前管理员的 V1 收件原话、批注及归档状态
jarvis_research当前管理员的 V1 研究、人工证据、方案及决定
jarvis_releases固定交付版本及人工验收记录；交付存在不表示已经部署
jarvis_knowledge来源有效授权的已发布原文与当前有效版本的故事
jarvis_memory本人private范围中已明确确认的active记忆
jarvis_family家庭共享且未移除的共同待办；不含健康备忘
jarvis_services实际服务台账和人工观察；不当作实时探测

工具由 defineTool 注册，从固定后台查询函数读取真实记录。单次最多 50 条，默认 20 条；当前没有任意 SQL、文件路径或网络地址查询。结果保留总数，并限制长度、过滤常见密钥字段；它们不是无限知识检索接口。

Pi 没有启用默认 bash/powershell/read/write/edit/grep/find/ls 工具，也不自动发现用户全局扩展、项目上下文或额外提示词。查询权限不能由资料内的指令扩大。业务修改仍由 V1 契约、权限、版本检查与事务控制；模型回答不能批准验收、发布或执行。

身份、存储与前端边界

- 当前真实会话只属于已认证管理员。家庭档案、声音和唤醒词不能代替成员认证。

- Pi 使用项目专用 <dataDir>/pi/agent 认证与模型资料；会话按 <dataDir>/pi/sessions/<actor>/<conversation> 隔离，路径由后台绑定。

- 服务资料目录使用账户权限保护；不读取或改写用户全局 Pi 配置，密钥不回显到浏览器。

- 完整真实平台默认入口 / 或 ?mode=platform；?mode=demo 使用独立演示状态；?mode=live 保留原 S0 控制台。

- 主题切换只重建主题视觉，不重建 Pi 会话；沉浸与收拢保留同一段对话。重新进入页面会从后台恢复已保存文字和 Pi 上下文。

- 浏览器语音识别需本人开启，可能由浏览器联网处理；识别文字先进入草稿。朗读使用浏览器声音，不等于房间语音平台或定制音色已经部署。

推荐接入顺序

  1. 先扩充可核验的查询与草稿。 给七个工具增加按记录 ID、范围和分页查询，保留来源与版本；让 Pi 输出结构化候选说明，由用户确认后调用既有 V1 命令，继续使用幂等与 revision 检查。
  2. 接开发执行器。 Pi后台单轮Worker已建立。连续开发还需本机执行器、真实日志、预算计费与验收回执，再接其他机器；聊天会话不承担常驻开发。
  3. 补家庭身份与个人资料。 明确每位成员的认证、授权、留存和遗忘规则，再接记忆与学习进度；Pi 按已认证成员加载受权限过滤的上下文，不能凭声音或档案选择读取私人资料。
  4. 接知识解析与课程。 OCR 服务产出识别候选，人工审核和校对发布形成确定的原文版本；Pi 负责解释、关联与讲述，引用固定出处，并保持原文与解读分层。
  5. 接房间语音与运行平台。 ASR/TTS、唤醒、回声消除和房间设备由专用接口负责，识别结果交给 Pi 做文本对话和意图分析；实际控制、部署、恢复与计费仍通过受控业务工具。

各阶段继续复用 Pi 的会话、模型目录、工具、Skill、事件、压缩、重试与打断能力；设备驱动、持久作业调度和业务验收由贾维斯平台实现。
