# 贾维斯 V15 · 图形化总览与大屏

原型文件：`贾维斯V15.0 · 十套主题与全平台交互原型.html`。本次将总览和大屏中的状态、关系与阶段改为图形表达，保留十套主题、20 个页面，以及对话图像占左侧 75%、内容与控制位于右侧 25% 的布局。

## 总览与全域大屏

- **全景地图**：可切换“领域”和“设备”。六个领域围绕贾维斯显示当前状态，连线表示领域汇总关系。点击进入对应大屏；中央入口打开语音对话。悬停或键盘聚焦可查看补充说明。
- **设备矩阵**：展示全部 21 台设备的最近状态，区分在线、休眠与离线。点击查看硬件、用途、项目和任务；公司 HP 保持只读接入范围。
- **四项状态环**：分别展示设备状态、任务状态、服务健康和待办审批的构成。数字与图形各自对应本类数据，点击进入完整管理页。
- **优先任务**：保留任务名称、阶段进度和状态，可查看详情、全部任务或切换监督。进度表示模拟任务阶段，不等于验收质量。
- **重点待办**：按紧急程度呈现审核、受阻和研究决策等事项，每项可直接处理。“审批清单”进入审批页；下方保留原文疑点、知识补充和服务检查入口。

## 六类领域大屏

| 大屏 | 图形与含义 | 可点击操作 |
| --- | --- | --- |
| 家庭陪伴 | 共同安排完成环，显示已完成数与总数；个人学习继续显示分钟、练习和天数 | 查看安排、完成事项、语音对话、语言陪练、听故事 |
| 知识神殿 | 原文阶段卡统计待解析、解析校对、人工精校、正式发布与异常；家人视图按可听故事主题呈现 | 阶段卡进入校对台，故事可听讲，补充建议可决策 |
| 运行管理 | 服务健康环区分健康、较慢、异常和离线；资源条显示人工、语音与后台预留 | 查看服务、发布过程、交付包，调整资源配额 |
| 开发监督 | 任务状态分布区分开发、验证、待执行、需处理、人工暂停和阶段完成 | 查看任务及监督规则，切换监督，查看项目与交付包 |
| 灵感研究 | 证据条区分支持、反证和待验证；阶段卡分别统计研究记录、研究推进、待决策与转项目 | 查看研究依据与方案，进入灵感记录或关联项目 |
| 经验技能 | 经验闭环呈现已记录、已验证、可用技能和累计复用，分别注明条数、个数与次数 | 查看技能版本、验证经验，快速记录新经验 |

图形沿用现有模拟数据，并随设备、任务、审批和记录等操作更新。资源条表示配额分配，实际负载在设备页查看；证据数量表示类别分布，不代表结论可信度。没有历史序列或学习目标的内容，未添加虚构趋势或目标完成率。
