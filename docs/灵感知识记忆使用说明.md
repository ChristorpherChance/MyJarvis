# 灵感、知识与记忆使用说明

本说明对应 MyJarvis 本轮新增功能。使用步骤、隔离验证、正式发布和现场验收分别记录；具体可用版本以实际发布记录为准。

## 随手收集

在“统一收件”中保存原话、粘贴链接、添加文档或图片，也可明确开始录音。录音停止后可回听、下载再决定是否保存。附件与录音先保存原件，原话、机器处理文字和人工校正分别留存。

- Word、PDF、图片可点击处理文字；扫描页依赖已配置的本机 OCR。
- 链接只有在明确点击处理后才会访问已允许的来源。网页保存为原件，动态页面或访问限制可能导致无法提取正文。
- 录音转写依赖真实 ASR 服务。没有配置时仍能保存、回听和下载。现已保留本地识别模型实际返回的时间分段，可在“对照来源定位”中回听；没有分段时不会编造时间。
- 提取文字需要本人核对，不会直接作为已发布知识或长期记忆。

本机已用固定中英文合成音频做真实 Whisper 小样验证：tiny 英文通过；tiny 中文未达到事先的逐字标准，同一音频换已有 small 模型后通过。没有自动更改当前设备或正式平台的默认引擎。这不等于真实麦克风、口音、噪声和长录音准确率已验收。

平台的普通草稿仍按当前浏览器及登录范围保留。需要断网后重新打开时，请提前准备下方独立的“离线收件”。普通草稿不会自行跨浏览器同步；下方密文同步只处理独立离线页中已保存的草稿，需要本人在当前窗口明确开启。

## 断网后重新打开与迁移草稿

在“快速记录”展开“离线收件与密文草稿导入”，打开独立离线收件页。首次联网点击“准备离线收件”，等页面明确显示准备完成，再保存这个地址。它只保留本页的程序文件，不保留平台身份、知识、记忆或服务器接口响应。

为本机离线草稿设置单独口令，之后断网重新打开仍可解锁并继续写文字、留链接、加文档图片或录音。最多 5 份原件，单件 25 MiB、合计 64 MiB。录音停止后可回听、下载；离线不转写或提取链接。输入后明确点击保存，未保存修改仍可能丢失。

口令不等于平台登录密码，至少 12 个字符，请使用自己记得住的长口令。草稿以密文保存在此浏览器，锁定、关闭页面或其它标签切换身份会隐藏已解锁内容。忘记本机口令无法恢复；浏览器清理本站数据也会移除本机副本，请保留密文备份。

迁移到另一浏览器时，先导出密文文件，再在目标浏览器的空离线草稿库中导入并输入同一口令。已有离线草稿不会被导入覆盖，错误口令或损坏文件也不会覆盖。这个过程是本人选择文件的迁移，不是自动同步或冲突合并。

联网后以当前管理员登录，在空的“快速记录”中选择密文文件、解锁并核对预览，再点击“确认导入当前草稿”。这会复制为当前浏览器的普通草稿；没有自动上传或提交。核对范围和原件后，再点击“保存记录”走原有收件流程。原密文备份保留。每次明确导入会创建一份新草稿，已送达或待确认的记录请沿原编号确认，避免重复导入。

## 本窗口开启跨浏览器密文同步

需要另一浏览器接着写时，可选择密文文件迁移，也可联网后开启“跨浏览器同步这份草稿”。远端只保留一个当前草稿副本，不会自动合并多份草稿，也不会替你提交到统一收件。

1. 以当前本人管理员身份登录。打开独立离线收件页，解锁本机草稿并保存，再点“启用本窗口密文同步”。单有旧管理员登录、当前却已切换成员时，不能开启。
2. 到另一浏览器，以本人管理员身份登录，打开同一离线页并明确启用同步。远端已有草稿时，输入“远端草稿原口令”，再点“选择远端并恢复本机”；已有本机草稿时，先导出备份，保留两份再选择。
3. 出现不同副本时，先比较页面显示的本机核对时间与远端更新时间。点“保留本机并更新远端”会把当前已保存的本机版本送到远端；点“选择远端并恢复本机”会用远端版本替换本机已保存副本。未保存输入要先处理；不要把时间较新当成内容一定正确。
4. 开启后，本窗口会在联网时同步后续已保存的密文。未保存输入、解锁后的正文和口令不会作为同步内容上传。断网时先保存到本机；如果页面提示结果尚未确认，点“重试同一次同步”，避免另外发起一次选择。
5. 点“停止本窗口同步”即可停止。锁定、离开页面、切换身份或材料会话变化也会停止并清除同步解锁输入；重新打开或解锁后，需要再次明确开启。
6. 如需移除远端，先点“删除远端密文副本”，再点“确认删除远端副本”。这不会删除本机或其他浏览器的副本；其他窗口发现删除后会要求本人选择，不会静默重新上传。它不等于底层介质擦除，也不清除自己另存的备份。

原口令只在本浏览器解锁，不上传服务器。忘记口令仍无法恢复远端密文；开启同步不能代替保管口令和密文备份。联网后要进入正式收件，仍须按上一节导入普通草稿、核对并点击“保存记录”。

## 管理原件

“统一收件”和知识资料候选均提供“原件管理”。可按文件名、访问范围及原件库/回收站筛选，查看原件、处理文字及业务和历史引用。

1. 移入回收站后仍可下载、回听；恢复后才可继续处理文字或新建关联。
2. 保留期限只锁定提前删除。期限到达也不会自动回收或删除。
3. 未引用清理只提供预览，每份原件仍要单独核对。
4. 永久删除只允许已回收、无业务或历史引用、不在处理或复用中且保留期已到的原件。确认前会列出当前条件，提交时再次核验。

永久删除会清除原件文件及保存的提取、校正文字，不能恢复。无正文的操作墓碑与指纹保留。当前业务记录已移除附件但历史提交仍引用时，也会阻止永久删除；本轮没有自动清除这些历史引用。

如果操作回包丢失，使用“确认上次操作”。不要换编号重新提交；当前版本或引用变化后，先重新读取并核对。

## 复用为知识

已存 PDF 或扫描图片可直接登记书目，无需再次选择本机文件。选择与原件范围相同、仍有使用授权的知识来源，再填写书目、页数、版本和使用范围。

平台核验原件字节后，复制到独立的书目原件存储，再走既有登记、识别、逐页校对及发布流程。登记书目不等于完成 OCR、校对或发布。DOCX、录音及其他材料继续作为资料候选，不被假装成已校对书页。

检索已发布知识后，可“打开命中内容”查看对应页码、版本、摘录和有限上下文。来源撤权或正文变化时，需要重新检索；实时全文没有保存时，只展示明确标注的当时摘录。

## 成员在房间页查家庭知识

在房间页展开“成员与房间连接”，用本人的成员档案 ID 和密码或 PIN“验证身份”。管理员登录不能代替成员验证。验证后，在“家庭知识”输入问题，明确点击“查找家庭知识”；输入文字本身不会自动查询。

这里只查当前成员获授权的家庭共享资料，包括已发布书页和已保存的来源正文。个人私有资料不会加入结果。“查找家庭知识”按字词与中文片段匹配；这个按钮不会启动模型问答、录音、转写或语音播放，也不实时抓取网页。需要换一种说法提问时，使用下方另行开启的“知识模型问答”。

点击“打开家庭知识出处”查看摘录、页码、版本及有限原文上下文。已保存来源会明确提示尚不等于人工审核通过。查询引用最多 5 分钟有效；打开出处时仍会重新核对当前授权和正文版本，过期、撤权或版本变化后需重新查询。

切换或退出成员时，同一浏览器标签中的旧问题、结果和出处会清除，录音会停止；其他已打开标签也会收到身份变化通知并遮挡旧内容，需要重新验证。若浏览器存储或跨标签清理无法确认，页面会明确提示，不能据此认为其他标签已清理。

## 比较和复核本人记忆

在“记忆神殿”点击“读取比较与到期复核”。系统只按相同字词或同类片段提示“可能重复”，不会判断语义冲突或自动合并。

- 比较两条：逐条查看内容和来源，自己填写最终表述，再明确确认合并。两条旧记忆停止召回，来源及审阅记录保留。
- 到期复核：选择“仍准确”或“已变化，我要更正”，再明确下次日期或留空暂不安排。日期到达不会自动停用记忆。
- 关联遗忘：合并前后的相关条目会一并列出，核对后再确认。正文、来源及相关旧回执正文一并清除，避免从旧提交恢复已遗忘内容。原聊天与独立收件需要分别管理。
- 提交结果未知：页面锁定原编号；刷新后可以继续确认同一操作。本标签待确认内容保存在当前登录范围的会话存储中，退出或登录身份变化后清除。

“按问题查找”只检索本人当前生效内容。候选、已合并或已遗忘的旧条目不会参与现行召回。“按问题查找”仍按字词与中文片段匹配；需要模型帮助理解不同说法时，使用单独的“本人记忆模型问答”。

## 用模型查询知识和本人记忆

“知识模型问答”可在知识页、知识来源页及已验证成员的家庭知识区域使用；“本人记忆模型问答”可在记忆神殿及本人房间记忆区域使用。先确认当前本人身份；管理员选择学习档案不能代替成员登录，也不能因此读取别人的私有记忆。

1. 查看面板显示的当前模型和本地或云端状态。尚未配置模型时，可继续使用原有的逐字查询。
2. 输入“知识语义问题”或“本人记忆语义问题”，勾选“本次启用模型查询”，再点“用模型查询知识”或“用模型查询本人记忆”。只输入问题不会自动调用模型。
3. 使用云端模型时，先核对本人的云端授权设置。尚未授权时，需按提示同意本次发送问题和当前授权摘录；只允许本地模型的设置不能靠勾选本次同意绕过。不愿发送时保留原设置，使用逐字查询或已配置的本地模型。
4. 回答出现后，逐项点“核对出处”，查看原句、上下文、页码和版本，再决定是否采用。已保存来源会标明尚未人工审核。模型回答不等于原文或人工结论；证据不足或核验未通过时，页面会说明，不能据此补写事实。
5. 需要结束时点“清除模型查询”。切换身份会清除当前问题、回答与出处并停止显示迟到结果；重新验证本人身份后再问。

知识只从当前授权的已保存资料中查找；本人记忆只使用当前已确认、生效的内容，不会把候选、已合并或已遗忘的旧条目重新当作现行记忆。这里不实时抓取网页。问题和提示不写入聊天或检索历史；选择云端时仍会发送本次已授权的问题和摘录。

出处短时有效，最多五分钟。每次打开都会重新核对授权和正文；来源撤权、版本变化、本人记忆更正或遗忘后，旧出处失效，应重新查询。正在生成的回答也会核对这些变化。已经看过或另存的文字不会因此从人的记忆或外部文件中消失，作决定前仍要打开当前出处。

每次模型查询最多三次模型请求，用于理解问题、回答及复核。按真实用量记账，不设消费上限；已知金额与用量分别记录，未提供价格的部分保留“未知”，不写成零费用。重新发起查询可能产生新用量，先查看页面的失败或证据不足提示，再决定是否重试。

## 发布状态与使用范围

R35已在112正式运行，可从[贾维斯平台](https://cc-jarvis.ikvein.com/?mode=platform)使用。每个要离线使用的浏览器，须先联网打开[独立离线收件](https://cc-jarvis.ikvein.com/offline-capture.html)并点击“准备离线收件”。正式HTTPS新空桌面浏览器的准备、断网重开及空草稿控件已经核对。

知识换种说法、本人记忆和缺证据拒答均有少量真实用例通过。同一个知识问题也曾被保守拒答，后在单独诊断中通过，产品源码未变；不能视为原问题已修复或稳定准确率通过。遇到“证据不足”，可使用原话关键词查询并打开当前出处。真实用量记账，价格缺失的部分仍为未知。

101已安装同版本代码、该批完整数据和语音环境，并完成一次常驻服务加载检查；业务和语音均留在停用状态。快照原时点与900秒新鲜度规则保持；超过期限会显示旧批次，不代表持续同步或自动接管。人工恢复顺序及语音启用条件见[主备部署说明](Linux主备部署与验收.md)。本次没有执行故障接管或生产数据回退。

仍需现场核对真实麦克风、不同口音、噪声、长录音、实体手机和房间终端；更广资料及提问下的模型回答与引用表现需持续复核。源代码见[MyJarvis](https://github.com/ChristorpherChance/MyJarvis)，本轮详细范围见[最终验收记录](版本记录/密文同步与证据问答验收-20261016-final.json)。

下载和校验文件已发布到[MyJarvis R35 Releases](https://github.com/ChristorpherChance/MyJarvis/releases/tag/20261016-capture-complete-r35)。公开主分支已合并本轮代码；GitHub源码与公开验收记录可直接查看。公开ZIP不包含数据库、凭据或语音模型，安装及恢复资料需另行妥善保管。
