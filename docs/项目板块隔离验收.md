# 项目板块隔离验收

本轮基线：`83fd4f8`。验证真实 `?mode=platform` 项目入口，不使用演示数据或旧 `?mode=live` 台账代替。完整软件工厂、真实101/供应商模型、服务请求管理客户交付另设证据门。

## 运行

在独立任务副本、普通账号运行：

```sh
npm ci
npx playwright install chromium
npm run build
npm run test:projects:browser
npm run test:projects:supervisor
npm run test:projects:controls
npm run test:projects:privacy
npm run test:projects:resume
```

Playwright固定版本由package-lock管理。浏览器未安装或前端未构建时先明确失败，不自动向生产回退。脚本不接受已有服务URL；使用专属临时HOME、环境白名单、`createApp`临时SQLite、显式独立运维/AI队列和禁用Python自动适配，Pi为禁止真实请求的替身。监听随机loopback端口并核对实例ID，浏览器仅允许同源，Node fetch仅允许fixture origin。这些是应用级隔离，不是操作系统级网络/文件沙箱。

启动前检查production目录、端口和权限边界，不能用 `withPlatform` 或直接写生产Store创建测试登录。日常 `npm run dev` 使用长期独立开发库，不是每次可删除的验收临时库。
