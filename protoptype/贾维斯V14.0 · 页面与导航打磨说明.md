# 贾维斯 V14 · 页面与导航打磨

新版文件：`贾维斯V14.0 · 十套主题与全平台交互原型.html`。单 HTML 离线体验，沿用十套主题、20 个页面、七类大屏和左右分区对话。

## 导航

常驻三个入口：**总览中心、语音对话、大屏中心**。其余功能分为四组；默认只展开当前组，同级名称统一四字。底部保留系统设置和全部功能，全部功能可搜索。

| 分组 | 功能 |
| --- | --- |
| 工作创作 | 统一收件、灵感研究、项目管理、开发监督、经验技能 |
| 知识学习 | 知识接入、知识神殿、原文校对、学习计划 |
| 家庭生活 | 家庭安排、记忆神殿、专属管家 |
| 系统运维 | 设备管理、运行服务、运维费用、待办审批 |

家人根据权限进入自己的功能；“经验技能”显示为“家庭资料”，“系统设置”显示为“个人设置”。公共空间只开放对话和家庭大屏。

## 页面

- 标题、菜单与顶部路径一致；每页用一句话说明用途，按钮直接说明动作。
- 研究与收件去掉重复背景文案；较长说明可展开查看。
- 原文发布门槛、私人资料范围与执行审批提示继续直接显示。
- 专属管家的保存操作放在页头；家庭共同事项排在生活帮助之前，家庭成员按需展开。
- 聊天、故事、原文、私人记忆和输入草稿保留原内容。

## 总览与大屏

总览先展示四项核心指标，再展示优先任务和重点待办，最后用六个领域摘要呈现全局。重点待办沿用业务优先级，部署失败、服务异常、额度和阻塞可优先出现。

七类大屏共用清晰的标题、领域切换和主操作。摘要精选重点记录；“全部”入口显示真实数量并进入完整管理页。详细列表自然滚动，手机按阅读顺序纵向排列。

桌面首屏以 1366×768、1440×900 校验；宽屏增加留白，手机保持可读字号和触控尺寸。界面指标与操作仍使用模拟数据。

## 验证

检查全部 20 页的深浅主题画面及手机横向适配；检查菜单、目录搜索、身份范围、关键表单与内容保存；复核七类大屏的首屏布局和异常优先级；回归对话、草稿、全屏、打断与十套主题切换。
