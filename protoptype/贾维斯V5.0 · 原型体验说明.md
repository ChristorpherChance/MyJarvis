# 贾维斯 V5.0 · 原型体验说明

日期：2026-10-03。用户已确认全部推荐方向，并强调家庭以语音为主、管理端适配电脑和手机、独立领域大屏与集合大屏。

交付文件：[贾维斯V5.0 · 高保真交互原型.html](<贾维斯V5.0 · 高保真交互原型.html>)。样式、脚本、图形和模拟数据均内嵌，双击即可打开，没有框架安装或外部 CDN 依赖。V4 原型另存保留。

## 1. 三种入口

- 默认打开：管理员总览，进入所有领域管理。
- 文件 URL 后加 #voice：直接打开沉浸语音终端。
- 文件 URL 后加 #screen：直接打开当前身份可见的总控或家庭大屏。

在语音界面点击“家庭终端”进入沉浸模式，管理员可返回“管理控制台”。切换为妻子、儿子、爸爸或妈妈时，默认进入各自语音空间。角色切换是演示，不代表已实现生产登录认证。

## 2. 推荐体验顺序

### 语音与家庭

1. 打开语音管家，选择闲聊、语言陪练、故事、生活、项目进度或快速记录。
2. 点击“演示这一场景”，无需麦克风即可看到理解、字幕、回应和后续行动。
3. 使用“打断 / 停止”，再开始一个新话题。
4. 选择“有歧义的指令”，比较开发任务、在线服务和书籍解析三个对象。
5. 切换家庭成员，查看独立对话、声音、唤醒词、交流节奏与学习状态。
6. 选择“公共身份未知”，确认私人资料与管理动作需要先确认档案。

可选择浏览器系统朗读和兼容的麦克风识别；具体声音及语音识别路径由浏览器和设备决定。仅本地偏好不自动启用可能联网的识别。普通家庭对话不会要求每次拿手机确认。

### 原文与知识神殿

1. 进入原文校对的“论语 · 学而样卷”，尝试在三个关键疑点未审时发布。
2. 比对模拟页图与两种识别结果，逐条提交裁决。
3. 进入逐页精校，按模拟流程完成页面审核，再发布正式版本。
4. 在知识神殿查看书目、三层资产、可点击知识图谱、正式故事与引用。
5. 创建个人课程、听故事并完成小测；切换成员观察学习记录隔离。
6. 修订原文，查看旧版本保留及派生故事失效；重核更新后再使用。
7. 在知识接入添加来源，选择本地、实时或混合模式；验证停用或撤权后不再召回。
8. 对缺口建议选择接受、暂缓或忽略，查看处理记录。

### 灵感、研究与经验

1. 使用语音、收件箱或灵感页面快速记录，保留原话、来源、终端和范围。
2. 检查重复候选，合并来源或保留独立记录。
3. 分流为灵感、经验、资料或私人记忆候选。
4. 在研究详情比较问题、假设、支持、反证、未知与方案。
5. 设置有限预算和时间，体验暂停、等待预算及重复失败边界。
6. 采纳后转为项目，目标、验收、里程碑和来源研究一起保存。
7. 在经验与 Skill 中完成验证、提炼、发布、使用和版本更新。

### 研发、交付与运维

1. 创建托管任务或项目里程碑计划，选择节点、Agent、目标、验收和预算。
2. 开启模拟监督或推进演示，观察执行、验证、阻塞、节点等待和额度等待。
3. 人工暂停后继续推进演示，确认暂停不会被自动解除。
4. 已验收托管阶段可生成交付包；阶段完成与整个项目交付分别记录。
5. 登记已有应用的主机、项目、环境、版本、运行方式与健康入口。
6. 从同一项目的交付包发起部署，测试环境按模拟授权策略进入待执行；正式环境进入统一审批。
7. 执行后分别选择验证通过或失败。失败后请求恢复，再完成恢复验证。
8. 查看部署回执、旧版本、恢复点和事件。暂停开发不会停止线上服务。

### 记忆与大屏

1. 在记忆神殿确认、拒绝、编辑或遗忘自己的候选。
2. 分别设置文字聊天、原始音频和长期记忆策略。
3. 在管家设定调整当前人的声音、唤醒词、语速、语言和交流风格。
4. 进入大屏矩阵，切换全域总控、家庭、知识、研发、运维、研究与经验大屏。
5. 在大屏上进入相关记录并处理，返回后查看联动状态。

应用管理员不会通过记忆界面或可见快照自动获得家人的私人聊天、记忆和私人收件。

## 3. 状态与演示边界

修改保存在当前浏览器的本地存储。刷新可继续查看模拟修改；恢复初始演示会清空本原型记录。系统设置和体验指南提供相应入口。导出只包含当前身份可见的管理或个人资料。

原型中的知识源、扫描页、OCR、AI 解读、检索、项目执行、机器心跳、天气、费用、部署、备份与恢复均为模拟。没有连接真实服务器、仓库、家庭设备或商业账户，也没有后台全天运行服务。

“30 页完成精校”用于快速演示状态和发布门槛，不证明真实书籍已校对。故事标明教学解读、版本与出处；真实材料仍需在系统建设时导入和审核。

## 4. 文件组织与验证

最终 HTML 是独立交付文件。开发源保存在 prototype-v5，构建脚本为 scripts/build-prototype-v5.mjs。这些源文件是继续修改原型的便利，不是打开 HTML 的依赖。

验证覆盖桌面与手机布局、主要视图、领域大屏、角色隔离、知识质量门槛、来源撤权、个人课程、收件去重、研究决策、开发暂停、部署审批、失败与恢复。相关报告和截图保存在 artifacts/prototype-v5-qa。
