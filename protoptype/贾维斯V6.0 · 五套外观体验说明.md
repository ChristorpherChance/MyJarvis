交付文件：[贾维斯V6.0 · 五套外观交互原型.html](<贾维斯V6.0 · 五套外观交互原型.html>)。双击打开即可体验，五套样式、实际界面预览、脚本和模拟数据全部内嵌在同一个 HTML 中。V5 文件保留。

## 如何比较

1. 默认进入外观库，在“管理首页 / 家庭语音 / 集合大屏”之间切换，比较同一场景的五种表达。
2. 直接点击一套“进入体验”，或点击“随机抽一套”。
3. 进入系统后，右下角的五个色点可立即换肤；“换外观”返回外观库。
4. 试过以后点击勾选或“记下我的选择”。选择保存在当前浏览器，没有向外发送。
5. 切换外观不会清空业务修改，当前页面、任务与审核状态继续保留。

## 更简单的进入方式

管理首页聚焦当前状态、最需要关注的三件事、正在推进的工作和六个领域。侧栏保留常用入口，较少使用的能力放进用途分类与可搜索的“全部能力”。

“全部能力”覆盖原系统的 20 个视图：总览、语音、知识接入、知识神殿、原文校对、记忆、管家设定、研究、收件、开发任务、项目、经验技能、在线应用、机器、家庭、学习、审批、费用资源、设置与大屏。进入后仍可使用原有表单、详情、审批、校对与执行演示。

家人的入口按角色过滤；公共身份只提供聊天和家庭大屏。管理员身份不会自动取得家人的私人记忆和聊天正文。

## 建议实际走一遍

- 家庭：语音管家 → 演示场景 → 打断 → 换成员 → 听故事 / 语言陪练。
- 知识：原文校对 → 疑点裁决 → 精校 → 发布 → 知识神殿故事与个人课程。
- 创造：随手记录 → 灵感研究 → 方案决定 → 项目 → AI 开发任务 → 阶段交付。
- 运行：在线应用 → 部署申请 → 审批 → 执行 → 验证失败 → 恢复与验证。
- 大屏：全域总控 → 家庭 / 知识 / 开发 / 运维 / 研究 / 经验六个领域大屏。

## 演示与文件

这是五套可交互外观的单文件原型。无需安装或外部字体、图片与 CDN。书页解析、AI 对话、项目执行、机器状态、天气、部署及恢复均为模拟；可选的浏览器语音能力沿用原型中的明确入口。

V6 使用独立本地存储，V5 的原文件与记录不被覆盖。刷新可继续当前外观和模拟记录。快捷键 Alt + 1～5 可切换五套外观；Esc 关闭外观库或能力目录。

源文件：`prototype-v6/`；构建脚本：`scripts/build-prototype-v6.mjs`；实际截图与检查报告：`artifacts/prototype-v6-qa/`。打开最终 HTML 不需要这些开发源文件。
