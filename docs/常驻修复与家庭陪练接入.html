2. 语言陪练

入口：家庭陪伴 → 语言陪练；房间入口可说“开始英语练习，聊聊今天”。

功能实际行为
练习计划选择英语、中文、日语、法语或西班牙语，A1–C2，1–12轮；题目由现有Pi SDK生成
逐轮反馈保存本人实际答句，Pi给出文字反馈、需要时的语法修正、示例及下一题
语音操作房间实际ASR结果进入陪练，反馈通过中央TTS；管理页面语音也使用中央引擎
学习记录本人点击“完成并保存学习”或说“完成并保存练习”才另存私人学习记录
时长按题目到实际提交的应答间隔计入，每轮最多5分钟；不是专注时长或自行编造的练习分钟
发音当前依据文本点评，没有声学发音评分、口音评分或虚构分数

识别与合成能否自然支持对应语言取决于实际语音引擎和声音配置。五种题目选项不等于五种语言均已完成实体收音和声音验收。

每轮生成单独检查本人云许可、身份、版本和取消状态；每轮最多60秒、USD 0.08运行上限，并继续接受已有费用门禁。没有配置Pi时返回明确提示，不回退成模拟老师。迟到的模型输出不推进已打断或撤权的流程。

3. 做菜流程与真实计时

入口：家庭陪伴 → 做菜指导；房间可说“教我做番茄炒蛋”。

先填写菜名、人数、口味、已有食材和需避开的食材。Pi生成食材与分步食谱，先停在待核对状态；本人确认后开始。食材和配料由使用者核对，模型建议不作为过敏安全保证。

可说“开始做菜”“下一步”“上一步”“开始计时”“计时两分钟”“取消计时”“完成做菜”“退出做菜”。计时1–3600秒，使用服务器到期时间及真实提醒队列；刷新页面可查看原到期时间，不重置计时、不重复提醒。

暂停流程保留已开始的厨房计时；切换步骤、完成或删除流程会取消当前计时。到时按本人的提醒渠道、安静时间和实际播放许可投递。计时不控制灶具，也不判定食物已经熟了；完成必须由本人确认。

提醒受理中断可用原提交编号重试恢复；如果尚未受理且期限已经过去，会明确提示未启动，允许重新计时，不制造补发成功。私人厨房提醒使用通用提示，不在公共房间播出私人食谱细节。

4. 个人记录与身份

管理页面即使切换了展示档案，陪练与做菜仍使用真实登录者。家人从配对房间验证本人身份，不能通过提交profileId替他人写记录。

本次流程默认临时保留最长2小时，绑定当前登录；本人可以明确选择保留7天或30天。到期自动移除流程正文，临时流程不能在另一登录中自动恢复。完成时另存的学习记录是独立、明确确认的私人记录；删除流程不自动删除学习记录。

删除流程会清除其问题、答句、反馈和食谱，并取消该流程计时。最小提交编号、内容指纹及对象编号保留90天，用于阻止迟到重试重新创建；不含原正文。学习记录由学习页面管理。原始录音继续遵守既有语音留存策略，陪练不额外保存音频。

Pi新增本人只读进度工具；管理员本人另可询问实际运行趋势。家人不会因此获得管理员的设备监控权限。

5. 设备与服务历史趋势

入口：设备管理 → 设备详情 → 运行趋势；运行服务 → 服务详情 → 探测趋势。

中央主机每10秒从本机操作系统读取CPU和内存，远端来自已配对节点的签名心跳。每节点每10秒最多保留一条实际采样，原始记录7天；15分钟汇总保留90天。图表支持一小时、一天、一周和三个月，显示均值与观测范围，断档保留空值。

服务历史来自配置的固定URL实际探测，保存状态和耗时。周期探测通过执行配置的 probes[].intervalSec 明确开启：0关闭，15–3600秒开启，最多并发2个；旧配置未设置该字段时保持关闭。可以继续使用原有的单次实际探测。

  "serviceId": "已登记的服务ID",
  "url": "http://127.0.0.1:端口/health",
  "timeoutSec": 5,
  "expectedStatus": 200,
  "intervalSec": 60

图表的探测成功比例只针对已有探测记录，不冒充连续可用率。GPU和功耗当前没有自动采集来源，保持未采集；人工功耗登记仍使用原有入口，不与自动历史混淆。远程服务原始日志没有在本轮接入。

6. 构建、备份与升级

常驻任务已经运行时，先在独立目录构建，通过验证后再升级。

升级脚本只控制已经运行的本项目进程，不启动Windows任务。它暂时停用固定入口、等待旧后台关闭、完整备份并核对业务库/执行库/语音密钥，原子换入新构建，再检查版本及实际子进程。备份或升级失败会尝试恢复原构建，保留数据和失败材料；不会自动覆盖业务库。

升级期间会有短暂不可访问。构建归档位于 artifacts/releases，私有完整备份位于 artifacts/backups。升级报告给出实际路径。备份含个人数据和凭据，只应放在本人控制的目录。
