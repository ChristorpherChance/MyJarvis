# GitHub 源码快照

本仓库保存贾维斯平台在 2026-10-15 整理的完整项目源码快照，目标仓库为 `ChristorpherChance/MyJarvis`（现为公开；按用户要求由私有改为公开）。这是代码备份与协作入口，不代表重新发布平台或完成软件工厂产品验收。

## 包含内容

- `apps/api`：后端源码、测试、Python/语音/知识处理运行资源。
- `apps/web`：前端源码、主题、静态资源及开发节点下载包。
- `apps/agent`：开发节点程序与示例配置。
- `scripts`：开发、构建、部署、验证和历史维护脚本。
- `config`：可分发的示例配置及公开模型资源清单。
- `docs`、根目录设计文档、`protoptype`：建设档案、建设日志、设计说明及历代交互原型。
- npm 工作区清单、锁文件和环境变量示例。

## 本地准备与构建

使用 Node.js 24 或更新的兼容版本，在仓库根目录运行：

```sh
npm ci
npm run typecheck
npm run build
```

开发模式使用 `npm run dev`；构建后可使用 `npm start`。服务读取系统环境变量，`.env.example` 只作配置参考，不会自动加载。首次运行、账号初始化、语音模型及部署步骤请查阅原有 README 和专题文档。

Python 资源依赖见 `apps/api/resources/requirements-local-runtime.lock.txt` 及对应子目录说明。模型文件、数据库和服务账号需在自己的环境单独配置。

灵感收件、原件管理、知识整理与本人记忆的操作及当前边界见[灵感知识记忆使用说明](灵感知识记忆使用说明.md)。这些新功能仍在草稿 PR 中，正式平台是否可用以发布和现场验收记录为准。

## 与原工作目录的边界

源码按文件清单复制到独立上传副本，原项目目录保留。Git 禁用自动换行转换，以保留源码原始字节及历史脚本中的指纹约束。

以下内容留在原机器，不纳入 Git：密钥和认证信息、私有服务器连接配置、`.jarvis`/`.jarvis-dev` 运行数据、`.maintenance`/`.deployment`、`serverinfo`、原始聊天与录音、历史现场证据 `artifacts`、已安装依赖、编译缓存和生成的应用构建目录。源码自带的示例和隔离测试数据保留。

部分历史维护脚本、报告链接及建设记录引用上述本地运行资料；克隆仓库不会同时获得那些历史环境，也不能用源码快照冒充原现场验收结果。部署脚本应先核对目标机器和自行配置的凭据再使用。

现有开发节点下载 ZIP 按原文件保留，其内部五项 SHA-256 校验匹配；其中 `jarvis-node.mjs` 与当前源码重建结果不同，尚未确认版本一致性。本次上传未重新打包或发布该下载包。

用户已暂停软件工厂每十分钟的目标修复与验收跟进。本次上传不会恢复该跟进、启动服务或触发生产发布。
