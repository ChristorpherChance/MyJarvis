# 灵感、知识与记忆使用说明

本说明对应 MyJarvis 草稿 PR1 的新功能。正式平台尚未发布这批代码；本机隔离验证和线上验收分别记录。

## 随手收集

在“统一收件”中保存原话、粘贴链接、添加文档或图片，也可明确开始录音。录音停止后可回听、下载再决定是否保存。附件与录音先保存原件，原话、机器处理文字和人工校正分别留存。

- Word、PDF、图片可点击处理文字；扫描页依赖已配置的本机 OCR。
- 链接只有在明确点击处理后才会访问已允许的来源。网页保存为原件，动态页面或访问限制可能导致无法提取正文。
- 录音转写依赖真实 ASR 服务。没有配置时仍能保存、回听和下载；本轮未确认真实识别准确率。
- 提取文字需要本人核对，不会直接作为已发布知识或长期记忆。

平台的普通草稿仍按当前浏览器及登录范围保留。需要断网后重新打开时，请提前准备下方独立的“离线收件”；未提交草稿不会自动上传或在浏览器之间后台同步。

## 断网后重新打开与迁移草稿

在“快速记录”展开“离线收件与密文草稿导入”，打开独立离线收件页。首次联网点击“准备离线收件”，等页面明确显示准备完成，再保存这个地址。它只保留本页的程序文件，不保留平台身份、知识、记忆或服务器接口响应。

为本机离线草稿设置单独口令，之后断网重新打开仍可解锁并继续写文字、留链接、加文档图片或录音。最多 5 份原件，单件 25 MiB、合计 64 MiB。录音停止后可回听、下载；离线不转写或提取链接。输入后明确点击保存，未保存修改仍可能丢失。

口令不等于平台登录密码，至少 12 个字符，请使用自己记得住的长口令。草稿以密文保存在此浏览器，锁定、关闭页面或其它标签切换身份会隐藏已解锁内容。忘记本机口令无法恢复；浏览器清理本站数据也会移除本机副本，请保留密文备份。

迁移到另一浏览器时，先导出密文文件，再在目标浏览器的空离线草稿库中导入并输入同一口令。已有离线草稿不会被导入覆盖，错误口令或损坏文件也不会覆盖。这个过程是本人选择文件的迁移，不是自动同步或冲突合并。

联网后以当前管理员登录，在空的“快速记录”中选择密文文件、解锁并核对预览，再点击“确认导入当前草稿”。这会复制为当前浏览器的普通草稿；没有自动上传或提交。核对范围和原件后，再点击“保存记录”走原有收件流程。原密文备份保留。每次明确导入会创建一份新草稿，已送达或待确认的记录请沿原编号确认，避免重复导入。

## 管理原件

“统一收件”和知识资料候选均提供“原件管理”。可按文件名、访问范围及原件库/回收站筛选，查看原件、处理文字及业务和历史引用。

1. 移入回收站后仍可下载、回听；恢复后才可继续处理文字或新建关联。
2. 保留期限只锁定提前删除。期限到达也不会自动回收或删除。
3. 未引用清理只提供预览，每份原件仍要单独核对。
4. 永久删除只允许已回收、无业务或历史引用、不在处理或复用中且保留期已到的原件。确认前会列出当前条件，提交时再次核验。

永久删除会清除原件文件及保存的提取、校正文字，不能恢复。无正文的操作墓碑与指纹保留。当前业务记录已移除附件但历史提交仍引用时，也会阻止永久删除；本轮没有自动清除这些历史引用。

如果操作回包丢失，使用“确认上次操作”。不要换编号重新提交；当前版本或引用变化后，先重新读取并核对。

## 复用为知识

已存 PDF 或扫描图片可直接登记书目，无需再次选择本机文件。选择与原件范围相同、仍有使用授权的知识来源，再填写书目、页数、版本和使用范围。

平台核验原件字节后，复制到独立的书目原件存储，再走既有登记、识别、逐页校对及发布流程。登记书目不等于完成 OCR、校对或发布。DOCX、录音及其他材料继续作为资料候选，不被假装成已校对书页。

检索已发布知识后，可“打开命中内容”查看对应页码、版本、摘录和有限上下文。来源撤权或正文变化时，需要重新检索；实时全文没有保存时，只展示明确标注的当时摘录。

## 成员在房间页查家庭知识

在房间页展开“成员与房间连接”，用本人的成员档案 ID 和密码或 PIN“验证身份”。管理员登录不能代替成员验证。验证后，在“家庭知识”输入问题，明确点击“查找家庭知识”；输入文字本身不会自动查询。

这里只查当前成员获授权的家庭共享资料，包括已发布书页和已保存的来源正文。个人私有资料不会加入结果。当前使用字词与中文片段匹配，不是同义或语义检索；这条文字查询不会启动对话、录音、转写或语音播放，也不实时抓取网页。

点击“打开家庭知识出处”查看摘录、页码、版本及有限原文上下文。已保存来源会明确提示尚不等于人工审核通过。查询引用最多 5 分钟有效；打开出处时仍会重新核对当前授权和正文版本，过期、撤权或版本变化后需重新查询。

切换或退出成员时，同一浏览器标签中的旧问题、结果和出处会清除，录音会停止；其他已打开标签也会收到身份变化通知并遮挡旧内容，需要重新验证。若浏览器存储或跨标签清理无法确认，页面会明确提示，不能据此认为其他标签已清理。

## 比较和复核本人记忆

在“记忆神殿”点击“读取比较与到期复核”。系统只按相同字词或同类片段提示“可能重复”，不会判断语义冲突或自动合并。

- 比较两条：逐条查看内容和来源，自己填写最终表述，再明确确认合并。两条旧记忆停止召回，来源及审阅记录保留。
- 到期复核：选择“仍准确”或“已变化，我要更正”，再明确下次日期或留空暂不安排。日期到达不会自动停用记忆。
- 关联遗忘：合并前后的相关条目会一并列出，核对后再确认。正文、来源及相关旧回执正文一并清除，避免从旧提交恢复已遗忘内容。原聊天与独立收件需要分别管理。
- 提交结果未知：页面锁定原编号；刷新后可以继续确认同一操作。本标签待确认内容保存在当前登录范围的会话存储中，退出或登录身份变化后清除。

“按问题查找”只检索本人当前生效内容。候选、已合并或已遗忘的旧条目不会参与现行召回。当前使用字词与中文片段匹配，尚未接入同义语义检索或真实模型问答。

## 仍需完成的环境与交付验收

- 真实 ASR 服务、识别准确率和录音时间定位；实体手机、麦克风及房间终端。
- 未提交草稿的后台跨浏览器自动同步及冲突合并；本轮提供显式密文文件迁移。
- 语义检索、真实模型回答及引用质量验收。
- 草稿 PR 评审合并、112 正式发布和现场验收；项目在线资料及重要决定的版本同步。

软件工厂每十分钟目标修复与验收跟进保持暂停。三大板块的局部功能不会改变原 74 项及客户 12 项尚未全部交付的事实。
