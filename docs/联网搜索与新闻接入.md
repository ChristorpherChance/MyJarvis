# 贾维斯 · 联网搜索与新闻接入

本轮接入真实公开联网资料，不以模型记忆冒充实时查询。接口经临时数据库、隔离 HTTP 服务和真实公共来源验收；未调用收费模型，未读取用户查询历史或改动正式数据。正式部署由统一发布流程完成。

## 能做什么

| 能力 | 实际来源与返回内容 | 边界 |
| --- | --- | --- |
| 联网搜索 | Bing 公开搜索 RSS，返回真实标题、链接、摘要和抓取时间 | 非商业搜索 API，没有 SLA；RSS 结果日期不等于原文发布时间 |
| 网页阅读 | 公开 HTTP(S) 网页静态正文，返回原链接、提取方式、是否截断和抓取时间 | 不登录、不转发 Cookie、不执行 JavaScript；登录页和仅脚本渲染的正文可能读不到 |
| 新闻查阅 | 中国新闻网滚动新闻、联合国中文新闻、NASA 官方新闻 RSS | 覆盖已配置来源，不能声称覆盖所有热点；可再用搜索和原文交叉核对 |

新闻保留来源报告的发布时间、更新时间和原始日期。它们不代表已核实的事件时间。无日期资料明确标记，超过查询时间窗口的有日期旧条目不会混入。某个来源失联时显示其失败状态；所有来源失联时明确报错，不生成替代新闻。

## 如何使用

家人通过语音或文字询问“今天有什么新闻”“帮我查一下最新资料”“读一下这个网页”时，Pi 可调用三个只读工具：`jarvis_web_search`、`jarvis_read_page`、`jarvis_news`。回答应附真实来源链接，需要时说明资料发布时间、抓取时间和来源覆盖范围。

本人资料策略为“仅本地”时禁止外部请求。策略为“每次询问”时需要用户本轮明确允许联网；模型不能在工具参数中自行授予许可。“允许外部处理”仍受服务开关、限流和当前身份有效性约束。工具没有登记事项、批准执行或修改成员资料的权限。

管理员可查看或修改联网策略和新闻源。设置必须带当前 `expectedVersion`，更新会终止旧请求并清空缓存。默认单次来源超时 12 秒，最多读取 1 MiB，结果短缓存 60 秒；每位成员默认每分钟 12 次、每天 200 次，服务整体还有并发和总请求上限。计数持久化；缓存只在内存中按成员隔离，不持久保存查询正文。

## 后台接口

| 方法 | 地址 | 作用 |
| --- | --- | --- |
| GET | `/api/runtime/web/state` | 本人能力与实际资料策略 |
| GET / PUT | `/api/runtime/web/settings` | 管理员读取或按版本保存策略 |
| GET | `/api/runtime/web/feeds` | 已启用的真实新闻源 |
| POST | `/api/runtime/web/search` | `{input:{query,count?,language?},networkConsent?}` |
| POST | `/api/runtime/web/read` | `{input:{url,maxChars?},networkConsent?}` |
| POST | `/api/runtime/web/news` | `{input:{feedIds?,query?,count?,withinHours?},networkConsent?}` |

全部入口要求有效成员或管理员身份。请求字段严格校验，不接受调用者自设身份、凭据、请求头、内部服务地址或搜索执行器。

## 安全与验收

读取前和每次重定向均检查 URL 与 DNS 全部解析结果，禁止本机、局域网、链路本地、云元数据、保留地址和非 HTTP(S) 协议。连接固定到已验证的 IP，TLS 仍验证原域名，避免第二次 DNS 查询绕过检查。限制重定向次数、体积、并发和耗时；客户端断开会取消上游请求。

网页与 RSS 正文是未信任来源。只提取文本，不执行脚本，不解析 DTD 外部实体，也不能让页面中的提示词改变权限、执行命令或批准任务。查询期间身份、资料策略或配置变化会阻止旧结果交付。

- 专项测试：`apps/api/test/web-runtime.test.ts`，覆盖真实隔离 HTTP、地址限制、DNS 变更、日期、权限、限流、取消和持久策略。
- 公共来源验收：`scripts/verify-web-runtime.ts`；结果保存在 `artifacts/web-runtime/live-source-smoke.json`。2026-10-10 实际获取 Bing 搜索、TypeScript 文档和全部三个默认新闻源，零收费模型调用。
- 契约扩展：`scripts/web-runtime-contract.cjs`，由统一接口契约合并流程登记。

## 来源说明

[Bing 官方 RSS 说明](https://blogs.bing.com/search/2005/1/RSS-Feeds-for-Search-Results/)将搜索 RSS 定位为公开实验能力；本接入明确展示其非商业 API 限制。默认新闻源是[中国新闻网 RSS](https://www.chinanews.com.cn/rss/scroll-news.xml)、[联合国中文 RSS](https://news.un.org/feed/subscribe/zh/news/all/rss.xml)和[NASA 官方 RSS](https://www.nasa.gov/news-release/feed/)。如以后需要更稳定或更广的搜索覆盖，可增加正规搜索 API，或部署配置了 JSON 格式的 [SearXNG](https://docs.searxng.org/dev/search_api.html)；当前未宣称已安装或启用这些后续方案。
