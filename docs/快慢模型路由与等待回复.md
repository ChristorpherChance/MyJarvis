# 贾维斯 · 快慢模型路由与等待回复

普通会话使用快速模型，研究、方案比较、多条件问题和医疗法律金融等需要仔细回答的问题使用高级模型。复杂度由本机规则判断，不额外调用分类模型。路由仅作用于管家与家庭对话，不改变全局默认模型、知识整理、项目开发或已确认后台任务。

## 配置与回退

在“系统设置 → 模型中心 → 智能路由”选择快速与高级模型，保存后下一轮生效。只接受 Pi 真实目录中已认证的模型。保存需要当前版本，会话运行时拒绝修改。快速模型未独立指定时沿用管家或家庭对话场景；高级模型未独立指定时只继承明确配置的深度研究场景。

没有可用高级模型时回到快速模型，并在本轮路由事件说明原因。本人仅本地或本轮未允许云端时，会检查最终实际选择的模型及 Pi 认证覆盖地址；云端高级模型不会绕过本地策略。快速模型也不符合策略时拒绝请求。预算或权限拒绝不会被自动切换模型绕过。

## 等待期间先回应

高级回答尚未出现正文时，可以在短暂延迟后调用快速模型的独立小会话。它只接收本机判断的题目类别，不传个人偏好、历史、家庭台账或原始复杂问题；没有工具，不读写主会话，也没有重试或自动压缩。

快速模型只从三种固定、无事实结论的等待句中选择一种。服务端严格校验 JSON 选项后，发出独立 `transition` 事件。非法输出、失联或超时不伪造等待回复。中文、英语、法语和德语分别提供对应句子。

一旦最终正文开始，等待会话立即取消；本轮最多一条等待句。停止聊天会同时取消两个模型会话。等待文字不加入最终答案、不写入主 Pi JSONL 或用户聊天消息。语音端把等待句与最终回答按顺序播放，最终正文继续正常展示。

等待回复也是真实模型调用，有实际 Token 记录、独立 runId 和治理预算预留，和最终模型用量共同计量。价格未知时记录未知费用，不能宣称免费或制造估算金额。输出上限 96 Token，默认超时 8 秒，默认启动延迟 700 毫秒；这些上限不等于实际首字或语音耗时保证。

## 本轮语言

输入语言由识别器自动判断；成员的固定输出语言单独决定回答表达。成员设置“英语输出”仍可用中文提问，父母设置“中文输出”也不将输入识别强制锁为中文。支持中文、英语、法语与德语；具体语音可用性由对应引擎决定。语言只改变表达，不改变身份、工具权限、模型目的地或云端许可。

## 首句与连续播放

R19 对稳定学科的普通中英法德问答，允许服务端审核完整短句后提前合成播放；后一句准备与当前播放重叠，短首句优先。涉及新闻实时信息、私人资料、执行操作及医疗等内容继续要求相应的依据和工具门禁，不能把未核实的模型流式草稿直接念出。

等待句缩短为中性提示，仍从固定安全选项中选择；不能提前宣称查到了新闻、执行了操作或已确认事实。首句播放优化、服务器引擎耗时与实际手机开始发声分别测量。现有测量及全天研发路线见 [全天持续研发与快速语音实施方案](全天持续研发与快速语音实施方案.html)。

## 接口与验证

管理员 `PUT /api/settings/pi/conversation-routing` 接受 `{expectedVersion,conversation}`。配置持久保存到服务器 Pi 私有目录的 `routing.json`，读取 `/api/settings/pi` 时返回 `routing.conversation`。配置含 `enabled`、`fast`、`advanced`、`transition`、`transitionAfterMs`、`transitionTimeoutMs`。

`apps/api/test/conversation-model-routing.test.ts` 使用真实 Pi SDK 与隔离模拟 Provider，验证实际发送模型、独立内存会话、无工具和无私人数据、固定语言、Token 上限、usage 记账、取消竞争、隐私及版本回退。测试不调用收费模型、不读取真实凭据、不修改正式配置。

当前分类是保守本地规则，可能把某些简单的“计划”“比较”问题送到高级模型，也可能漏判隐含复杂问题。实际响应速度受模型服务、网络、上下文和 ASR/TTS 等多环节影响；“快速模型”是配置角色，不能由名字推断真实延迟。
