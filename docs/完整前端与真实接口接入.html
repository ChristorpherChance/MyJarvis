Pi 的使用原则

继续使用已安装 Pi SDK 的模型运行时、AgentSession、SessionManager、认证、资源加载、流式事件和 abort，不另造一套模型客户端。智能判断通过 Pi 运行；业务对象、版本、授权和交付状态由业务接口校验。

Pi 当前可调用 7 个只读工具：项目、设备、任务、经验、收件、研究、交付版本。收件/研究/项目/经验页可把讨论草稿送到 Pi 对话，由本人确认发送。模型回答不会自动成为已验证证据、批准决定、已启动执行或实际部署回执。接入范围见 Pi SDK 接入说明。

后续研究、知识解读、疑点整理、课程建议、意图识别和记忆候选优先复用 Pi；ASR/TTS、文件存储、OCR 输入输出、设备采样、远程执行和费用账单仍需专门服务。它们的真实结果交给 Pi 理解，而不是用模型文字替代执行结果。

接口与数据保护

V1 沿用原管理员 Cookie 会话。请求不允许冒用成员或对象所有者；家庭范围当前是管理员管理的资料范围，尚不代表家人可独立登录。

命令使用 { commandId, expectedVersion, scope, payload }。打开表单时固定对象修订与范围，冲突不自动覆盖新记录。响应中断后的相同提交复用 commandId，不重复建对象；表单等待提交、保留失败输入，成功后刷新实际记录。保存已成功但刷新失败时明确提示刷新，不要求再次提交。

退出和会话失效清除界面私有记录。旧认证周期的请求不得覆盖新会话。主题与本机通知偏好单独保存在浏览器，不存 API 密钥、业务正文或 Pi 草稿。

V1 当前 149 个操作中，54 个标记已实现、95 个待实现；36 个命令处理入口已接。54 是接口处理统计，包含明确拒绝未就绪执行器的入口，不能理解为 54 项完整运行能力。每个操作的具体能力以 OpenAPI 状态和运行能力为准，接口存在不代表执行器就绪。逐接口状态 · OpenAPI 契约。
